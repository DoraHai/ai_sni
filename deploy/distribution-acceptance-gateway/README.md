# Independent SEO acceptance HTTPS gateway

The standard advisor entry is `https://gsnipers.snipers.com.cn:58443/customer-workbench/?console=advisor` only after actual external HTTPS and ordinary browser verification. Until then it is a candidate address. This separate port isolates browser localStorage from production 443. It forwards only the existing independent SEO service, preserving native JWT, role/scope checks and the single-publication fence. Device APIs continue using the private test tunnel.

The instance, PID, logs and root-owned configuration prefix are `/opt/gsnipers-distribution-acceptance-gateway`, outside the API user's writable parent. The existing public certificate/key are loaded by the root master without copying, changing or printing private key data. Workers use `distacceptance`. The upstream TCP target is fixed to 127.0.0.1:55861; strict CA and hostname verification use its existing `DNS:localhost` SAN. Production Nginx is not reloaded or reconfigured.

`scripts/distribution_acceptance_gateway.py install` requires a clean exact source commit and the caller-pinned SHA256 of `artifact-manifest.json`. All installed configs and the startup verifier are read from Git blobs and checked against that pinned manifest. **Bootstrap must also be safe:** export the reviewed controller blob locally, upload only to a fresh root-owned 0700 bootstrap directory outside API-writable paths, verify its SHA256 against the reviewed manifest before executing, and keep that file root-owned 0600. Do not execute a controller from an API-writable checkout as root merely because it can verify itself later.

Installation first checks actual native SEO health, then starts only the independent unit, verifies local public TLS with ordinary certificate validation, and temporarily permits 58443/tcp for two hours. Cleanup intent is persisted before adding the runtime port. The unit remains disabled for automatic startup. The script does not change cloud security groups or assert public reachability. If a security group blocks this port, add the exact scoped rule through an authorized cloud console and verify external TLS; do not disable certificate checks or install a root CA in user browsers.

The stop command checks the installed ownership/hash manifest, stops only this unit and removes only its planned runtime port. It preserves files and the native database. Cloud admission requires its own cleanup. Stopping this gateway does not cancel native tasks: separately stop the executor and use the existing project pause/revoke rules before concluding a publishing task cannot act.

This is a bounded test entry, not a production rollout or permanent certificate-renewal integration. Actual publication, account/content verification, native writeback, customer/advisor display and foreign-customer denial still need independent evidence.
