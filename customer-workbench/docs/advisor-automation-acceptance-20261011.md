# 顾问项目自动推进：开发与验收基准

日期：2026-10-11。本文件记录开发范围、本地验收证据和生产验收边界，不表示已经发布或已经开启真实客户项目。下列首批站内 AI 的版本与结果是历史基线；本輪项目工作流 v2 的最终候选、覆盖和限制见文末。

## 范围与责任

项目控制按客户、模块、网站或项目绑定，不按登录账号各启动一套 AI。当前顾问只能读取和控制后端仍分配给自己的范围。账号切换、顾问分配变化、权限撤销、来源版本变化均需重新核验。

首期接入 SEO/GEO 已存在的业务能力；接口必须返回真实覆盖范围，未接入的 SEM 调度、任意工具发现、官网自动修改不能被统一按钮宣传为可控能力。AI 不可自行开启项目、扩大范围、修改额度、批准方案或宣告业务验收完成。

## 控制语义

| 动作 | 必须成立的行为 |
| --- | --- |
| 开启本次运行 | 明确范围、目标、负责人、运行方式及调用上限；默认一次运行；重复提交不能产生第二次运行或供应商调用 |
| 暂停 | 停止新步骤和新外部请求；已发请求进入收尾；不得把暂停请求等同于所有在途调用已结束 |
| 恢复 | 重新核对真实身份、分配、权益、来源及任务版本、额度和当前状态；不能自动重发已经付费但结果未知的步骤 |
| 人工接管 | 自动推进失去写入资格，保留现有进度；人工修改后旧自动结果不得覆盖当前方案 |
| 结束本次 | 停止本次剩余步骤；保留调用和证据；不修改业务审批、网站实施或人工验收状态 |
| 结束项目 | 结束当前运行并关闭后续周期；保留历史；重新开启前必须重新保存明确配置 |
| 停用周期 | 停止后续周期建单，当前运行按自身状态处理；不删除历史、不撤回第三方已发生操作 |

运行结束、方案生成、发布完成、业务交付验收、排名/收录/引用效果分别记录。不得由其中一种状态推导其余状态成功。

## 进度与成果

顾问可以看到当前项目控制状态、当前或最近一次运行、执行步骤、执行主体、开始/结束时间、实际结果、阻塞原因、等待的人工角色、下一步，以及可回到原模块核验的成果记录。

步骤计数以真实计划与步骤状态为依据，不用估算进度条冒充执行事实。AI 文案、格式通过和供应商响应成功不能成为 SEO/GEO 效果提高的证据。效果缺少真实观测时显示未观测或待验证。

## 持久化日志

控制操作和执行事件只追加保存，按运行及范围分页读取。至少包括事件序号、时间、客户/模块/项目/运行/步骤、human/system/ai 主体、真实操作者、动作、前后版本或状态、安全原因码、对应请求与成果引用。外部调用的原估算、核实金额、费用未知分别表达。

不得存储密钥、密码、完整令牌、未脱敏请求正文或任意供应商原文。日志写入失败时不得静默继续新的付费步骤。未知调用保持未知，不使用强制释放或归零。日志不得仅存在浏览器内存或截断的任务展示历史中。

## 界面与接口验收

- 进入、刷新、筛选、读取日志不触发 POST，不启动 AI，不自动开启周期。
- 数据库或接口未就绪时显示未接入/待启用，不给出假成功按钮。
- 控制仅允许固定同源模块接口，精确绑定 tenant_id、scope_id、run_id；调用前读取最新记录并复核实名身份及可用模块。
- 控制写入带版本和幂等编号；结果未知禁止自动重发，先读取权威记录核对。旧响应不能跨账号、跨项目或跨版本显示成功。
- 人工接管、暂停与外部返回发生竞争时，保留真实计量和安全事件，失效结果不得自动应用。
- 权限撤销清除控制、步骤和日志；每个模块独立展示读取失败，不以另一个模块的正常数据替代。
- 真实 Edge 验收覆盖开启、暂停收尾、恢复拒绝、人工接管、结束本次/停用周期、日志分页、成果链接、未知写入、权限撤销和移动布局。

## 发布前提

本轮新结构及运行账户权限须按仓库 AGENTS.md 完成人工审核；此前 API 台账的建表批准不能代替此次审核。开发和测试不自动执行生产 DDL、启用保护或项目开关，也不发送付费探针。

后台共享调度器可以待命，但未启用、无到期工作、等待人工或已结束的范围不得因此发起新的自动付费调用。真实生产覆盖、调用价格、保护开关和恢复/连续运行仍按实际发布版本独立验收。

## 首批站内 AI 的接入范围（历史基线）

首批只控制通过项目配置排入队列的 SEO/GEO 站内 AI 草稿任务。入口标题和按钮均明确这一范围。人工主动发起的单次 AI、排名/竞品/外链采集、内容/诊断/监测/月报旧周期、GEO 巡检和分发，以及 SEM 自动化均不能因该批暂停被宣称已经停止。各模块接口实际返回的 `coverage.not_controlled` 会直接显示。

项目日志覆盖尚无运行编号的配置事件；历史运行可以单独查看，查看期间禁用当前运行的写入按钮。等待人工时停止自动刷新，页面隐藏和编辑配置时不继续刷新；连续读取失败停止刷新，不因此重发控制写入或供应商请求。顾问选择来自当前授权任务页，最终任务归属、事实、版本和适用范围由模块服务再次校验。

上线前须补齐独立模块部署、共享新表及执行角色权限的人工审核、生产工作线程与队列健康核验，并在受控范围完成实际启动/暂停/接管/结束演练。业务要求的全项目总开关还需逐类接入上述现有周期、巡检、分发和 SEM，不以本轮站内 AI 控制替代。

### 当前执行顺序

1. 人工准备并确认客户范围、服务计划、资料、重点词/问题及负责人。
2. 顾问读取当前授权依据，明确选择操作、目标、引擎/渠道、调用上限及一次/周期方式，保存配置。
3. 顾问单独开启本次运行。保存、浏览和读取日志均不会替代开启操作。
4. 系统按选定模块能力推进步骤；AI 只参与已接入的草稿工作，不自行寻找任意工具。每次外部请求先持久化准入，返回后记录真实结果和费用证据。
5. 自动成果回到原模块，顾问核对事实和质量；网站应用、审批、发布放行、客户确认及业务验收由人完成。
6. 已接入的观察步骤记录实际监测/评估。缺少可比数据或出现未知付费结果时等待人工，不虚构效果、不自动再次付费。
7. 本轮产出后等待顾问处理。结束本轮后才能安排已启用的下一周期；结束项目同时关闭当前运行及后续周期。

只接管当前配置中选定的范围和操作，暂停或结束后不会交回旧调度器自动继续；未选入的存量能力仍依原配置运行。人工单次操作与项目自动推进分别显示。每个客户、网站/项目独立运行，SEM 没有接入本批自动推进。

已保存的接管操作不能通过新配置直接删除。结束项目也保留接管归属，防止旧调度器在用户要求停止后重新运行；本批没有把操作交回旧周期的解除接管入口。后续配置可以保留操作并替换其有效目标，缺少目标时等待人工准备。前端目标移除单元测试使用合成服务器，验证草案资料绑定整理，不证明后端允许删除已有接管操作。

长期日志保留策略、跨进程心跳汇总、真实供应商费用核实、真实模型方案质量及生产持续运行仍需各自的实际证据；本轮没有付费请求、生产 DDL、生产开关变更、推送或部署。
