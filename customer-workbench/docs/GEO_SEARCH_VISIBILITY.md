依赖后端草稿 PR #687；PR1 `5fc14c5` 的 CI 和 Cursor 严重/高问题均通过后才开始本 PR。
前端联调复核另促成后端 `02a265e1` 的精确路径超管门禁修正，最终验收需包括该增量。
本 PR 独立基于最新 `codex/production-sem`，不包含后端提交。上线顺序必须先 PR1，再 PR2。

## 当前入口与发布边界

现有 `frontend/geo-frontend` 路由复用 `frontend/src/views/geo/*` 的内容、回答指标和巡检页；
项目级客户/顾问工作空间则已在独立 `customer-workbench` 发布单元的 `geo-workbench.mjs` 实现。
因此本轮沿用工作空间选择器进入 GEO 项目，卡片位于项目首页，右上角“项目设置”即配置入口。
超管控制台的平台总览和成本页增加月用量一行，同属该静态发布单元，不拆分其他发布线。
不改 SEM 源码、原回答指标、原巡检或交付报告，不新增路由入口或登录方式。

## 展示与操作

- 顾问/超管：收录、前20名命中词、文章存活三张卡；最近8周趋势；逐词名次与前排链接；
  首页与文章原始链接；失败原因；“立即跑一次”和CSV下载；项目设置包含全部已批准字段。
- 客户：关闭可见时完全不显示该块；开放后展示相同数字与明细，没有设置、运行按钮或失败细节。
- “待启用”、无数据、运行中和失败分别显示，不把未完成当成功；失败趋势不画连线。
- 设置读取失败保留已经读取的结果；身份失效则仍清空。未执行的失败项显示“尚未确认”，不冒充0。
- 运行中每3秒只读取进度，不再发送运行请求。页面隐藏或打开设置时暂停轮询，保留输入。
- 同租户推荐词由顾问选择进当前项目；客户可见开关默认关闭，说明先顾问使用4周。
- 固定解释：这是 DeepSeek 搜索引擎能不能搜到你，不等于 DeepSeek 回答里会提到你。
  时间直接使用后端的北京时间 `YYYY-MM-DD HH:mm`，供应商时间字段不显示。

## 范围和身份保护

客户宿主仅增加本次已核验项目路径，查询只允许唯一 tenant_id，路径项目必须和宿主一致。
设置/运行复用现有 GEO 顾问权限；全平台用量只通过已核验的超管客户端。
设置仅发送白名单字段，不接收或存储服务密钥；结果链接只允许无用户密码的 http(s)，所有文字转义。
身份、项目或权限变化清空显示，延迟响应和CSV读取后再核验范围；运行结果不明时不自动重发。
下载要求真实CSV响应，不能把“暂未开放”等JSON保存成表格。
