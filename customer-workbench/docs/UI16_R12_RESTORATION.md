# UI16：恢复 r12 首页与常驻对话

2026-10-09。用户指出正式工作台与确认原型偏离，授权先修改。此轮仅客户工作台前端，本地实现；不修改 SEO/SEM/GEO 后端、登录、数据库或生产配置，不发布。

## 设计基线与修正

基线：工作机 梳理-2026-10/客户界面方案/r12-tier-homes。

| r12 结构 | 上一正式版本 | 本次修正 |
| --- | --- | --- |
| 主栏 + 常驻对话 | 单列内容；稿件下方折叠消息 | 桌面恢复双栏，右侧常驻输入、上下文、快捷问题、收起/展开 |
| 本期要点 | 三个计数卡 | 待办、进度、页面问题要点，可进入明细或带题询问 |
| 次级指标 | 稿件/局部待确认/任务 | 六个可点击指标：稿件、关键词、页面、问题页面、发布登记、核验发布 |
| 任务优先 | 功能列表 | 要点、紧凑指标、任务待办、数据详情的顺序 |
| 数据固定入口 | 二级页面中已有 | 保留原导航并增加首页关键词分布、制作状态、最近进度、页面检查 |
| 对话带上下文 | 仅单篇消息 | 数据导览跨页面保留；稿件顾问消息默认展开，切身份/客户清空 |

## 真实能力与尚缺项（不能宣称已全部还原）

- 首页复用已鉴权、已核对客户/网站的 GET：content-assets、service-status、关键词、site-pages、publication-page-evidence、执行列表。部分读取失败只标缺失，401/403仍由宿主清除整个授权范围。
- 不接入演示数字。不把前20个词/前8篇稿的状态比例当作全站统计；不把已备好视作已确认、不把发布记录视作核验成功；过期排名不参加有效名次分布。读取时间与来源观测时间分开。
- AI模型对话接口尚未接通。本次导览是本地规则 + 已读数据，明确标“非AI回复”，不请求模型、不外发问题、不执行指令；无会话持久化。不能称为智能体接入完成。
- 顾问消息继续使用已有单篇稿件会话；全客户自由会话未增加后端。首页保留入口说明，打开稿件后实际消息面板默认展开。
- 当前首页为存量概览。任意日期范围、全站搜索点击曲线及三模块真实数据没有在本次补造。SEM/GEO真实接入、原型多模块档位仍待后续对齐。
- 原稿件阅读、图片、轻改、审核、确认、版本保护、顾问代确认、交付记录、服务计划和数据明细均保留。
