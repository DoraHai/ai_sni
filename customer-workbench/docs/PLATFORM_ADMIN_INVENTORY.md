## 服务端接口

独立 SEM 后端发布单元新增 `GET /api/v1/admin/console/snapshot`。要求实名 JWT、无客户绑定、
同时具有 settings.accounts 和 settings.customers 编辑权。运行 API Key 不作为此页面的登录身份。
每次请求从原鉴权逻辑读取最新账号与权限，服务器拒绝客户、运营及单项管理角色。

`POST /api/v1/admin/console/controls` 采用同一鉴权边界；只接受 budget/provider/rate/credential 四类操作。
写入使用 UUID 幂等请求、配置版本检查与同事务审计。浏览器保存前重新核对身份，密钥字段立即清空。

固定表/字段白名单读取共享数据库，不依赖其他模块模型版本，不修改业务数据，不执行迁移。
独立只读事务和每条语句 3 秒超时。基础清单最多 1000 条；调用 50 条、各类任务 30 条，
响应包含总量与截断标记。缺表/缺字段返回 unavailable 和 null，不伪装成空清单或零。
读取异常由现有错误处理返回错误，前端清除上次快照。

只提取明确用量字段，不返回 module_settings、任务 params、request_meta、原始错误、
密码哈希或凭据。接口地址剥离用户名、密码、查询参数与片段，错误码与请求号限制为机器标识。
响应 no-store/private，前端只保留内存快照，会话退出、身份切换、权限变化及 401/403 后清除。

## 解释边界

- 调用与费用均来自 api_usage_events，覆盖已接入的外部服务商调用，不能推算启用前成本。
- GEO 的真实接口配置不代表连通测试成功；不自动执行测试采样。
- SEO 的 workbench_chat_requests 可能同时计入 ai_requests，不能相加估算总成本。
- API 费用与客户广告投放预算分别展示；没有价格/账单依据时不显示 0 元。
- 维护入口复用既有客户、账号、角色页面，本次不复制一套业务编辑器。
- 日/月金额预算按保守估算预留，未知价格、未知金额无法通过金额预算；不等于服务商账单硬保证。
- 单价与密钥变更仅影响新请求；百度授权沿用原流程。实际账单对账、外部通知及灾备监控待接入。

## 验收

测试涵盖服务端权限与凭据排除、原生 PostgreSQL 只读快照和缺表、浏览器登入/拒绝、
所有导航、筛选、401/403、身份切换的迟到响应、桌面与手机布局。
保留客户工作台契约与构建发布校验。上线通过已有 SEM 后端和静态发布流水线，
前端维护入口沿用现有页面；本次共享请求准入通过 SEM/SEO/GEO 各自独立发布。
新管理表需人工审核后执行，`API_CONTROLS_ENABLED=true` 后管理表单可用；不默认设置预算或更换密钥。
