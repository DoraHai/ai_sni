# UI13 产品可用化本机验收

日期：2026-10-08。仅独立 `customer-workbench/`，本地提交，未推送、合并或部署。用户经总控明确授权可用化与合成资料/关键词维护验收。UI12稿件确认、发布登记和任务推进没有重播。

## 本批完成

- 首页独立展示当前网站稿件总数、已核对稿件中的待确认、任务记录和最近进度。单次最多取8篇并读取各篇delivery，最多5项任务；待确认同时要求 `awaiting_customer_confirmation` 与对应 `allowed_actions`，不从ready推断、不无限扫描。有限覆盖明确标注。
- 稿件、计划、意见、人工登记和维护表单的未保存输入：离开时留在/放弃；409/500后保留内存文字，同对象重读并打开表单后显式恢复。恢复绑定对象及人工登记记录，不恢复授权、旧版本前提或人工核实勾选；身份/租户变化、401/403、已核验顾问撤销清空。没有自动提交或自动重试，也不跨会话存储草稿。
- 客户隐藏顾问编辑、审核、登记、AI/周期配置及维护表单；客户计划为方向、选题、备注只读摘要。顾问动作依据服务端能力和本站分配显示。任务页顾问动作亦按服务端允许值显示。
- 正文安全排版只保留允许的文字/结构，重新创建元素，不复制原属性或执行原脚本。图片与嵌入内容不加载，清楚提示存在未预览内容。确认记录和当前动作分开，旧退回不着绿色成功态；确认仍不等于发布。
- 消息栏成为默认收起的小入口。保留浅色布局和390px手机支持，表格横向滚动附提示。中文状态/北京时间显示；内部版本、来源与原始证据折叠。
- SEO工作展示准备事项与真实指标；数据展示关键词排名、页面检查、资料及详情。关键词支持文字/引擎/设备/状态查询，页面支持文字/状态查询，均真实服务端过滤和20条分页。缺失观测保留缺失；不把0评分当缺失，不把允许索引当已收录。
- 交付记录每次从分页发布页面投影读取，可跨会话查看持久记录，并进入稿件/发布详情。没有平台或日期假筛选；关联覆盖partial有提示。报告继续通过持久任务详情读取/下载。
- 顾问可新增/编辑资料（完整字段+版本、启用/停用、北京时间到期选择器）；新增关键词，以及修改优先级和目标页。每次打开/保存重新读取顾问资格；资料有版本冲突保护，关键词明确提示最后保存生效。编辑未改变到期选择值时保留原始时刻。

## 有边界的交付

- 已完成本批可用化，尚未生产发布或统一生产网关验收；本机auth目录桥和合成数据不代表生产全量用户场景。
- 发布交付为服务端分页历史；当前没有按客户汇总所有历史确认的接口，稿件仅显示delivery提供的最近确认记录。报告走独立任务记录。没有伪称一张表包含完整确认/发布/报告全历史。
- 本轮没有真实排名、真实抓取、外部平台发布、真实AI生成或冻结报告全流程；页面观测缺失不会合成结果。
- 资料接口最多返回500条、无total；排名与页面列表统计口径、单词历史的地区口径均保留说明。未覆盖真实大规模数据和全部筛选组合。
- 维护仅包含最小前期建设流程：无批量导入、关键词改名/归档/高级配置；关键词写端没有乐观锁，页面如实提示多人最后保存生效。
- 未接消息发送；图片/嵌入原稿需要顾问核对。草稿只在本次授权会话内存保留，浏览器关闭或明确放弃后不恢复。
