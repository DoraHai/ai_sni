# UI14 图片阅读与大量数据验收

2026-10-08。本批只修改独立 customer-workbench；没有直接操作数据库、执行外部AI/采集/发布或部署。沿用隔离本机 FastAPI/PG，由SEO维护合成数据。最终提交与干净构建的准确证据由交接回报记录，避免文档引用自身提交造成循环。

## 用户可见变化

- 正文 HTML 图片与简单 Markdown 图片按原顺序展示，保留 alt 说明。加载中、失败和重试都有明确状态，不能静默省略。原尺寸弹窗可滚动，按钮或 Esc 关闭并返回焦点；桌面和390宽手机可用。
- 未加载完整的图片会在正文前提示；点击确认时再次明确提醒，取消不会发起确认请求。
- 内容列表增加真实服务器搜索和状态筛选。稿件、关键词和任务详情提供返回列表，保留原有页码；稿件/关键词保留筛选、滚动位置和入口焦点。不同数据页分别保存页码。

## 图片读取契约与边界

授权图片仅识别同源 `/api/v1/seo/site/page-captures/{id}/image`，先GET对应元数据并核对 `id/tenant_id/site_id`，再GET图片；仅允许当前 tenant_id 查询参数。`source_url` 是被截图页面，不能当作图片下载地址。继续使用既有宿主会话，不向任意地址附加令牌。

公开图片只允许 HTTPS，通过浏览器 CORS 读取，省略凭据和来源信息并拒绝重定向；没有通用后端代理。不允许跨站读取、失效、错误格式和超限均保留失败入口。支持 PNG/JPEG/WebP/GIF/AVIF，最大10MiB，读取20秒超时；超时信号贯穿授权传输和响应体。身份/站点/内容版本变化时中止请求并释放临时blob。复杂Markdown语法、SVG、任意嵌入视频等不在本批支持范围。

## 验收范围

`npm run test:ui14` 覆盖读取契约、授权范围、请求及响应体取消、图片顺序和说明、跨站请求不带凭据、站点不匹配拒绝、失败重试成功、原尺寸关闭、手机宽度及未完整查看取消确认。夹具仅本机内存数据，不代表生产测试。

真实只读脚本 `scripts/ui14-real-readonly.mjs` 使用本机原session登录接线，分别运行客户和顾问：

| 任务 | 多页任务，第2页详情及返回页码 |
