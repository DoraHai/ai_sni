G-Snipers 国内填稿助手（本地开发版）

1. 解压整个 ZIP，在 Chrome 的 chrome://extensions 或 Edge 的 edge://extensions 打开开发者模式，选择“加载已解压的扩展程序”，选中解压目录。
2. 在 SEO 国内分发中心生成分发任务，从“发布任务”导出待填稿任务包，或在单篇交接台导出。
3. 点击扩展图标，导入 JSON 任务包，选择账号和文章，打开官方平台并登录。
4. 进入图文/文章编辑器，再打开扩展；核对账号，分别点“填入标题”“填入正文”。可先点选对应编辑框，避免多个编辑区无法判断。
5. 检查封面、图片、分类、原创/AI 声明以及正文是否在平台真正保存，再自行发布；复制公开链接回工作台确认。

只在用户当前打开的受支持官方域名上按需填文字，不读取账号密码或 Cookie，不调用私有发布接口，不点保存/发布按钮。正文以文字填入，图片请在官方后台上传；需要富文本时用交接台的“复制正文（保留格式）”。
任务文件含正文和账号标签，请妥善保存；扩展仅在 chrome.storage.session 保存，浏览器关闭后清除，也可手动清除。导入新包替换旧包。
已存在文字/图片、无法唯一识别编辑区、跨域 iframe 或自定义编辑器不支持时停止，使用复制粘贴。填入不是发布成功，工作台只在回填并验证链接后计入已发布。
本地适配逻辑已经模拟编辑器测试，真实平台账号兼容性尚待验收；本版本不宣称全平台无人值守发布、定时发布或登录账号托管。
