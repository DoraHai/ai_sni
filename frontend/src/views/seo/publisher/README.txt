G-Snipers 国内分发助手 0.2

1. 解压 ZIP，在 Chrome 的 chrome://extensions 或 Edge 的 edge://extensions 打开开发者模式，选择“加载已解压的扩展程序”，选中解压目录。已有旧版时，用新版目录替换并重新加载。
2. 在 SEO 分发中心生成任务，从“发布任务”或单篇交接台导出 JSON；在助手导入，选择对应账号和文章。
3. 打开官方平台并登录，进入编辑器。核对账号后填标题、正文；也可使用“复制图文排版”粘贴富文本。平台可能过滤图片，需要核对并补传原图。
4. 检查封面、图片、分类、原创/AI 声明及正文保存情况，在平台自行发布。助手不点保存或发布按钮。
5. 打开已公开的文章页，在助手“采集当前文章链接”。核对文章与任务一致，勾选确认，保存结果并处理下一篇。
6. 全部完成后导出发布结果 JSON，回到分发中心“发布任务”选择“回收助手发布结果”，预览后批量确认。回收不会再次向平台发布；任务 ID、平台和稿件版本必须匹配当前网站。

任务、账号标签及进度保存在本机 chrome.storage.local，关闭浏览器仍保留；完成后点“清除任务”。导入新包会替换旧任务和旧结果，请先导出已完成结果。任务包和结果文件需自行妥善保管。

不读取账号密码或 Cookie，不调用平台私有发布接口。已有内容、无法唯一识别的编辑区和跨域 iframe 不覆盖。账号登录、验证码、平台必填项、图片上传和最终发布由操作员处理；无法填稿时使用复制粘贴。

填稿不等于发布，回收登记不等于发现外链。工作台会另行扫描公开页面并展示外链证据。真实平台账号/编辑器兼容性尚待逐一验收；本版不宣称全平台无人值守、定时发布或会话托管。
