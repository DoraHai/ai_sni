# 本地 GEO 页面验收环境

在 frontend 目录运行 `node tests/local-geo-smoke/server.mjs`，打开
`http://127.0.0.1:5276/tests/local-geo-smoke/index.html`。

实际挂载信源分析、快照和编辑器 Vue 组件。所有 axios 请求由内存适配器处理，
没有后端代理、真实凭证或模型请求。仅允许内存建任务和保存任务，其他写操作抛错。
CSP 限制网络到本机。服务只监听 127.0.0.1，不读取 Vite 环境变量。

客户 A 有 3 条固定快照和一个机会，客户 B 为空。第一次创建任务计数为 1，重复打开不会增加。
可保存行业等创作要求，返回机会再打开验证保存；刷新整个页面会重置模拟数据。
原文中包含 script 标签文本、引用中包含 javascript 地址，用于确认页面按文本展示和禁用不安全链接。

这是人工浏览器冒烟测试入口，不是生产站点，也不能替代后端 HTTP、数据库、真实登录和并发测试。
在启动终端 Ctrl+C 停止服务。不要部署此目录。
# 异常路径控制

工具栏可使已读取证据过期、让下一次保存失败，或延迟下一次保存响应。
验证竞态时：在任务编辑器点击“延迟下次保存”，点击“保存设定”，等待工具栏显示“保存响应等待中”，点击“客户 B / 当前页”，再点击“释放保存响应”。旧客户标题和编辑内容均不应恢复。
这些控制只修改本地内存模拟接口，不能用于验证真实数据库或服务鉴权。
