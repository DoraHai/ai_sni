# GEO 渠道适配：母稿 → 中国分发平台文稿

> 状态：已实现 · 分支 `cursor/geo-channel-adapt-b24b`  
> 前置：内容闭环（Wave A）+ 可见度（Wave B）

## 0. 中国内容分发主渠道（本产品取舍）

面向 **GEO / B2B 可信内容**（非纯娱乐短视频），中国当前主力文稿分发大致分三层：

| 层级 | 渠道 | 本产品 | 说明 |
| --- | --- | --- | --- |
| 自有 | 官网 / 帮助中心 / 博客 | ✅ `website` | AI 与搜索最稳信源；母稿保真 |
| 必争图文 | 微信公众号 | ✅ `wechat` | 品牌主阵地；人工复制发布 |
| 问答/百科向 | 知乎 | ✅ `zhihu` | 高意图提问；利于直接答案摘取 |
| 搜索生态 | 百家号 | ✅ `baijiahao` | 百度系分发与摘要 |
| 信息流图文 | 头条号 | ✅ `toutiao` | 资讯体、标题党风险需控 |
| 后置 | 小红书 / 视频号 / 抖音 | ❌ 本切片不做 | 偏种草与短视频，另立适配器 |
| 后置 | 新闻媒体发稿 | 走媒体策略页 | 非「母稿改写」主路径 |

**默认任务渠道：** `website` + `wechat` + `zhihu`（百家号/头条可选勾选）。

## 1. 目标

- Channel Profile 驱动确定性改写（无平台 API、无自动发文）
- 编辑器：多选渠道生成 + Tab 预览 + 过期（stale）提示
- variant 记录 `adapt_meta`（profile / 裁剪说明）

## 2. 非目标

- 公众号/知乎 OAuth 一键发布  
- LLM 润色（可下一切片挂 L2）  
- 小红书/短视频脚本  

## 3. 验收

- [x] `GET /channel-profiles` 返回中文渠道画像  
- [x] 可选生成 wechat / baijiahao / toutiao  
- [x] 母稿升级后 variant `stale=true`  
- [x] 编辑器 Tab 可预览/复制各渠道稿
