# GEO 第二批：统计口径与快照证据

日期：2026-09-05。仅保留本地改动，未提交、推送或部署。

## 本批行为

- 统一指标服务的日期窗口和全时段入口默认排除模拟样本。识别模拟布尔值、mock_persona 来源及历史备注中的模拟标记；显式 exclude_simulated=False 仍可供内部分析使用。
- 统计读取不再为决定过滤规则创建或读取租户 AI 设置。导出预检显式检查包含模拟的全集，保留原有仅真实采样导出的拦截行为。
- 从已有 note 读取 method/analysis 标记，不改数据库模型，不回填历史记录。无方法标记的 API 样本记为 legacy，不冒充 v2。
- 样本构成增加 API 方法计数、混用提示、待复核数量和历史方法警告。混用不同方法、v2 判读缺失或明确待复核时，统一指标序列化结果隐藏百分比、保留分子分母和原因。
- 快照列表始终展示来源；证据弹窗提供已保存回答、问题、采样时间、引擎、方法、判读状态和记录的引用。引用只允许打开 HTTP/HTTPS 地址，回答按文本渲染。
- 切换租户关闭并清空证据，快照加载丢弃过期请求结果，防止旧租户或旧筛选结果覆盖当前列表。

## 验证

- GEO Python 回归加既有统一指标测试：460 通过，无跳过。新增异步用例通过 asyncio.run 执行，不依赖 pytest-asyncio。
- 前端既有 Node 检查：6 通过；GEO 独立前端构建通过。
- 新增来源兼容、方法混用、判读失败/缺失、过滤开关、日期/全时段入口一致性、上海时间窗口和租户查询约束测试。
- 新增后端测试已加入两份 GEO 工作流的测试清单；没有运行部署工作流。

## 适用边界

- API 回答不代表用户端搜索结果。方法标记存于可编辑备注，目前不是防篡改证据链；引用仍需独立核验。
- 历史单一方法窗口保留原有数值兼容性，同时提示历史方法不明；没有宣称历史样本满足品牌中立采样条件。
- 本批保护统一指标服务输出；未重写日聚合存储、巡检 run 内部对比及其他自行计算指标的旧路径。纯计算对象保留原始数值，调用者应读取序列化输出及 sample_composition 判定后展示。
- 目前展示方法构成并拦截混合结论，尚未增加按方法重算的历史趋势筛选或人工复核完成流程。
- 未连接真实数据库、调用真实模型、启动生产服务或完成登录页面的浏览器端到端验收。前端构建仍有既有大包提示。
- 后续可推进购买决策问题库、引用来源机会清单和证据绑定任务；全面客户交付前仍需实库并发验证及统一旧报表路径。
