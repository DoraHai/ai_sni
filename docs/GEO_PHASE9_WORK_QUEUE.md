# GEO 下一步工作 · 本地第一版

入口：GEO 文章工作台 `/geo/tasks` 顶部“下一步做什么”。沿用当前客户及全局观察期。

- 没有可用机会样本：提示确认重点业务问题、采样并完成判读。
- 待复核或引用不准确：提示核验原始回答和引用，保留不准确标记直到有依据修正。
- 弱引用线索：提示同题补充采样，不提供内容创建按钮。
- 重复引用线索：列出问题、原因、具体动作和验收要求；支持查看同题回答、创建或打开已有内容任务。
- 已有内容任务：根据任务状态给出下一步和验收要求；已发布任务可进入同题复测，不将发布等同有效果。
- 有可用样本但未触发规则：明确说明只是未发现本规则覆盖的机会，不声称没有业务缺口。
- 接口失败或缺失机会字段：显示错误和刷新入口，不显示无工作结论。

范围：这是证据驱动的建议队列，不是新建的通用工单系统。核验和采样建议尚无独立持久化完成状态；没有新增负责人、期限、自动发布或自动效果验收。内容任务仍复用现有持久化接口和去重逻辑；建议可能继续出现，由创建/打开接口复用已有任务。既有任务列表按原有分页展示。没有增加数据库表，也没有修改其他业务模块。

任务列表读取增加请求代次保护，切客户或改变筛选时不显示旧列表。建议队列同时保护刷新、切客户和离开页面后的异步响应。修正了任务状态标签空 type 引起的组件警告。

验证：前端 20 项检查通过；GEO 构建通过（geo-work-queue-build.txt，仍有既有大包提示）。本地实际 Vue 页面、内存接口验证：有证据的工作建议显示完整原因/动作/验收；从建议创建任务并跳入编辑器；返回后任务列表显示下一步；切到无样本客户后显示补采样建议且旧任务清空。实际后端、数据库和生产环境没有调用。
