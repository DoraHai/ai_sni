# GEO 第三批：有样本依据的内容机会

日期：2026-09-05。仅本地修改，未提交、推送或部署。

## 使用入口

在「信源分析」查看「有样本依据的内容机会」。按问题展示核对顺序、样本数和观察依据；展开查看建议行动及对应快照，点击快照直接打开已保存回答的证据弹窗。可导出逐条问题、建议与证据对应的 CSV，供人工评审。

## 规则

- 使用当前租户、当前观察窗口内的快照和问题；复用 citation-insights 的鉴权、时间过滤和自有域配置。
- 仅纳入 API 来源、unprimed_json_v2 方法、判读 completed 的非品牌点名题；排除人工/模拟、旧方法、待复核、问题缺失，以及已标记引用不准确的样本。页面逐类展示排除数量。
- 每条快照去重，每个问题计算可用样本、含第三方引用样本、其中未提及品牌的样本、自有域引用样本。
- 同题出现第三方引用且存在品牌未提及，或已配置自有域却未见自有域引用，生成核对机会。没有配置自有域时不判断自有域缺口，并说明引用归属尚待确认。
- 至少 3 条引用样本且覆盖 2 个引擎标为「优先核对」，其他机会标为「补充采样」。这个阈值只是可解释的内部工作排序，不是统计显著性或市场评分。
- 证据保留快照 ID、引擎、采样时间、品牌提及标注和引用 URL；同 URL 去片段去重，拒绝非 HTTP(S)、带登录凭据及无效端口的 URL。
- 建议先核验来源及品牌事实，再补充内容并用同题复测，不推荐没有样本支撑的固定渠道排名。

## 页面变化

- 布局建议改为上述机会的摘要，原固定渠道清单保留为明确标注的参考清单。
- 信源页加载时清空旧结果，并丢弃旧租户/旧观察窗口的迟到响应。
- CSV 导出对公式前缀进行文本处理。快照原文仍按文本渲染，不执行模型内容。
