## 当前执行流程与人机边界

1. SEO/GEO 模块产出方案、母稿和渠道稿；品牌事实、客户范围、当前审核及有序素材保持原生门禁。AI 可建议和产稿，不能给自己批准发布。
2. 超管绑定客户/网站或项目/设备/本地账号/平台真实标识，明确配置发布规则。多号通在独立窗口保存设备凭证，原程序和已有账号会话不读取或覆盖。
3. 顾问核对审核稿和目标账号，显式开始项目并授权本次人工发布。系统自动检查账号时段、间隔、日上限、占用及暂停原因，原子预占后派发任务；没有启用的账号或项目不运行。
4. 当前多号通领取冻结内容和实际配图，校验摘要、真解码并准备人工交接。真实渠道填写/上传适配仍关闭；公众号候选只读检测不能凭“匹配到字段”自动启用。
5. 人工在平台完成发布并回填公开链接。验证码、登录失效、结果未知或矛盾都停止推进；未知结果保留占用，先人工核查，不能自动重发。
6. 顾问可运行机器初检。仅检查固定官方公开地址的文本和元数据，不使用登录会话、不跟随跳转。即使文本和账号匹配，也仍为待人工；CSS 可见性、完整展示及配图无法由静态 HTML 证明。
7. 顾问加载**本次发布的冻结稿**与全部有序原图，对照公开作品，逐项确认公开可访问、目标账号和完整内容。三项都确认才登记人工核验。记录只增不改，保留顾问、时间、链接、版本和事件关联。
8. 中央在同一事务的保存点调用 SEO/GEO 原生回写，再次检查当前权限、审核、版本和摘要。写入失败只回滚原生侧，保留核验与待回写台账。顾问“仅重试模块回写”不会再次调用发布任务。
9. 原模块检查及效果监测继续独立处理。工作台显示已登记与待原模块检查；**发布核验、页面检查、搜索收录、AI 引用和业务效果分别记录**。SEO 还需把已提交的检查预约接到原有 worker，完成重启补偿与生产环境验收。

历史发布核验允许项目 paused/ended，仍要求当前顾问权限和有效原生范围；不要求旧设备租约继续有效。原生审核撤回或来源变化会阻止首次回写。正文不会被新版草稿替换；配图当前原生读取拒绝时，顾问不能借旧任务绕过。

## 技术与验证依据

- 设备 v1 协议保持不变。新增实名顾问接口位于 `/api/distribution/v1`：`publication-source`、`publication-assets/{task}/{asset}`、`publication-check`、`publication-writeback`；任务列表附带独立核验和回写状态。
- 冻结稿重新验证来源版本/摘要；原图重新验证当前授权、不可变 ID、长度/SHA256、PNG/JPEG 真解码、单帧、像素上限。浏览器复核 SHA 与类型后才创建 Blob，切换范围、重新读取或权限变化时撤销 Blob 地址。
- 公开页仅允许两平台固定官方 HTTPS 主机和规范路径，无参数/凭证/重定向；全 DNS 答复必须为公网地址，TCP 固定解析 IP，TLS 使用原官方主机。最多 2MB、4 个有界工作线程、网络期限 10 秒及外层 11 秒期限。HTML 解析最多深度 128、20,000 个事件与每次 0.25 秒预算；超限归待人工。
- 网络读取前释放数据库事务，回网后再次核验实名身份、角色与范围。设备→范围锁、请求幂等键、不可变检查记录和每任务唯一回写阻止并发重复登记。结构或模块不可用时保留明确待处理状态，不显示成功。
- 中央最终后端回归 **76 项通过、0 失败、0 跳过**：真实 loopback PostgreSQL/JWT、并发/暂停/权限撤销、失败保存点、真实字节素材、实际 Node/FastAPI/TLS/多号通交接，及机器初检不会创建原生记录的回归。来源与平台页面均为合成数据，不访问真实平台。

## 可评审组装包与上线前仍需处理的部分

脚本 `scripts/package_distribution_review.py` 只读取四个**干净提交**，先核对组件改动范围，再打包各自基线补丁和 SHA256 快照；绝不执行 SQL、部署或覆盖源码。工作台产物必须来自包内中央提交、`sourceTreeClean=true`，并逐字节核对产物、源码与锁文件。生成的新目录及 ZIP 放 TEMP，清单记录确切提交；LF Git 快照与构建所用工作区字节摘要分别保留。

  --central 'D:/SNIPERS国内版/ai_sni-worktrees/distribution-control-20261011' `
