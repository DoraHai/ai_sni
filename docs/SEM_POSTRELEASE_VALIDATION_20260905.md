## 发现并修复

告警 upsert 将已有告警恢复为 `open` 时，没有清除旧 `resolved_at`，造成状态为未处理却保留
处理完成时间。关键词和实体两条路径均通过真实 PostgreSQL 测试复现失败，再修复通过。

修复只清除重新命中告警的旧完成时间；沿用既有重新打开/更新优先级规则，不改告警归并规则、
数据库 Schema 或其他模块业务代码。不会对生产历史数据进行回填。
