# 多号通 v2 SEO 实现与边界

本分支接续草稿 PR #779。共享库同一性与唯一迁移归属按2026-10-19 20:44的 INFRA-DECISION 已放行；此前准备阶段的数据库阻塞已解除。本轮只开发、测试、审计、普通提交和推送，不合并、不部署。

统一入口 `/seo/distribution-inbox` 在 SEO 商业壳外挂载，只需要正常人员身份。GEO 壳打开相同身份页面或复用独立 API；不能把当前 GEO 业务 JWT 当身份 JWT。身份页面使用原身份会话，标注时在内存里临时取得目标客户业务会话，不修改全局当前客户。失效/更换身份后清空数据、请求和临时业务会话。GEO-only、零客户授权顾问能配对，不能标到未经授权的客户。

身份 `GET /api/v1/seo/distribution/v2/inbox/targets` 返回当前可标客户、有效模块与授权范围；人员管理员额外得到有设备的所有者列表，用于筛选离职者未标箱。SEO 网站按当前分配；GEO 项目只读检查共享 `geo_projects.project_settings.geo_service_plan.advisor_user_id`、`geo_business_scope.business_ids`、业务归属、模块/项目状态以及顾问 GEO 权限；与 production-geo 的项目规则一致，不从 SEO 导入 GEO 运行时。SEO 仅处理 SEO 标注/撤销/发布投影；`/api/v1/geo/distribution/v2/...` 由独立 GEO 服务及 geoV2 PR 实现，不在 SEO 进程注册或代写。既有同源分流不改变。

唯一迁移 `0110_distribution_inbox`（父 `0109_advisor_tenant_grants`）只新增 `distribution_inbox_devices` 和 `distribution_inbox_receipts`，无角色/ACL/env/原表修改，无 downgrade。GEO 使用字节一致 ORM 定义。不存在表时 v2 返回503，旧版原样。若任意收件表在 alembic_version 尚为0109时已存在，整笔升级拒绝并回滚，不能猜测接管或自动修表；已成功登记0110再次upgrade是无操作。部署 workflow 只修改预期head一处，生产升级留待以后单独批准。

所有者 User 行锁→设备→receipt 的一致事务顺序；管理员代操作按用户ID排序同时锁原所有者和操作者，再锁当前角色、grant、模块、范围、稿件。设备认证每次复核在职、锁定、角色、停用和90天有效期。凭据/码仅存摘要，只返回一次；已使用码不重发凭据，领取未知需吊销重配。已知码限速持久化于设备JSON，未知码IP/摘要/总量兜底为进程内有界桶，不声称跨worker全局防护。

同device+eventId唯一，已持久ACK先于新事件时钟、容量、限流判断恢复。ACK在提交后返回，设备查询不返回客户归属。归档不释放容量；清理内容保留事件摘要/原ACK墓碑，本轮不提供物理删除或180天后自动清行。90天未标按接收时间在查询/投影中进入归档视图，仍计入容量。每owner未标1000条/10MiB，总保留5000条/50MiB；总字节另计修订JSON，历史512次硬限，不能靠改标无限膨胀。达到上限拒新事件，已持久ACK仍恢复；无80%预警。

只有原owner或人员管理员可标注/改标/撤销；每次要求expectedRevision。客户/模块切换必须原模块撤销，再重新标注。失去原目标权限要由管理员撤销，身份接口不能逃过业务授权。其他顾问只能读当前授权且已分配非空范围的外部投影。所有写响应共用字段投影；历史只返回不带目标/操作者的动作时间，失权owner不能看到当前或历史目标。成功链接按客户+模块+范围（空范围0）+规范URL哈希唯一；冲突不泄漏另一行，哈希相同而规范URL不同返回固定人工核对错误。

SEO分发页的发布记录加入独立“外部回传记录”，与原生已发布数量、KPI、稿件验收分开；不造稿、不插必填稿件表。可选关联必须通过现有客户确认/顾问代确认、固定版本及摘要检查。当前所有平台仅记录，未接安全页面抓取或新核验任务；无稿件显示unlinked，有稿件显示unavailable，绝不显示verified，旧核验也不会借来冒充v2通过。范围/稿件/账号修改使当前修订变化并重置核验。标题/账号纯文本，链接无自动预览、noopener/noreferrer/no-referrer。

无导出、邮件、自动上传历史、平台凭据读取、账户登录、原生发布状态写入、客户归属转交、后台自动建表或新增开关。运维只读核对与未来操作顺序见共享 RELEASE-STEPS.md；本轮未执行任何生产操作。
