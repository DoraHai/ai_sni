# GEO 发布链接回执

在「分发记录 → URL 回填 → 导入回执」上传。一次仅处理当前文章和所选项目；没有项目归属的历史文章需先由有权限的人员设置归属。预览逐行给出「能导入／不能导入／无需导入」及原因，有错误时整批不写，重复行跳过。确认会重新读取同一文件并校验当前审核、项目归属和发布条件。

沿用 SEO #670 的 UTF-8 CSV/JSON 容器、字段 `article_id/platform/public_url/published_at`、2 MB 和 200 行上限，以及先预览再确认的操作。GEO 只登记已发布链接，不处理 SEO 发布单、账号和三态任务；两者并非直接互导协议。请下载 GEO 页面模板填写。无网络抓取、无自动发布。

CSV 表头：

```csv
article_id,platform,public_url,published_at,note
999999,website,https://example.com/demo-article,2026-10-20T09:30:00+08:00,假数据示例请替换
```

JSON 使用对象数组，相同五个字段。`article_id` 是当前 GEO 文章任务编号（不是母稿版本号）；支持文本或整数。`platform` 填页面列出的渠道值，或已有渠道画像／同值注册渠道的名称；只匹配当前文章实际已有的渠道稿，不把未知渠道映射到其他渠道。未来新增渠道值无需修改导入白名单，但仍须具备现有单条回填需要的渠道稿。

`public_url` 必须是完整 HTTPS 地址，不含账号信息或空格。`published_at` 可省略或留空，留空由现有写入函数登记当前时间；非空必须带时区，例如 `2026-10-20T09:30:00+08:00`，入库转 UTC。`note` 可省略，最多 1000 字。

可选 `variant_id` 对应当前文章渠道稿编号；可选 `tenant_id/project_id` 必须与本次选择一致。可选 `status` 仅接受 `published` 或空值；未发布／结果不确定的记录不计作成功。未知字段拒绝，防止误导入 SEO 或其他格式。模板例子完全是假数据。

同一链接（忽略主机大小写、默认端口和页内锚点，保留查询参数）或相同渠道记录不会重复写入。同一条渠道记录填了不同链接会要求先核对；已有其他链接的渠道记录不被覆盖。不查询文件中其他客户的文章／记录编号，统一提示不属于当前范围。后端沿用当前权限、租户隔离、GEO 开通检查、项目业务及问题归属、加锁发布门禁和 `_write_publication` 状态流转，不修改权限规则、不加迁移。
