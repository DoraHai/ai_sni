## 顾问与超管操作

1. 超管绑定客户、网站/项目、设备、本地账号与平台真实账号标识。平台账号的历史客户归属不能通过停用再绑定改写。
2. 超管显式配置发布时区、时段、最小间隔、系统日上限并启用。没有配置或没有启用时，不派发 publish。规则按平台真实账号共用，覆盖同账号的各设备和项目。
3. SEO/GEO 继续产出母稿和渠道稿。小红书素材从原生授权上传入口存入数据库，图片清单包含内部 ID、长度、格式、SHA256 和顺序；换图必须重新审核。SEO 还要求另一位有效顾问审核素材，GEO 延续客户审核门禁。
4. 顾问开始项目分发，核对完整审核稿和目标账号，独立授权人工发布。顾问能进一步收紧项目日上限和间隔，不能放宽超管规则。
5. 系统先判断账号时段、间隔、日上限和占用，再原子预占账号、下发任务。跨设备并发也只有一项发布占用。执行中的任务遇到暂停、验证码、登录失效或时段关闭，会收到 pausedTaskIds。
6. 顾问查看任务状态、回执、等待原因、下次可执行时间、系统占用和日志。超管能查看全局最近 100 条分发操作日志，包括规则修改、账号暂停/恢复及任务核查。额度显示的是系统预占/确认发布计数，平台剩余额度始终明确为未核验，不能据此保证平台风控或站外人工用量。
7. 结果未知时保留账号占用，跨天也不会重发。顾问须确认已核查平台、已停止本机及人工操作，再记录未发布或已发布；已发布必须提供相应平台公开链接。
8. 核查记录只增不改。旧设备迟到报告与“未发布”结论冲突时，保存回执、暂停账号、撤销同稿后续授权，等待纠正核查。暂停后迟到的发布报告保留为 unknown，不直接标为授权内完成。

人工报告的链接没有通过公开内容核验，页面不能宣称机器验收成功。项目结束后不能恢复；本机 stop 与项目 pause 是不同操作。

## 设备图片交付

固定 GET `/api/distribution/v1/device/tasks/{taskId}/assets/{assetId}` 使用该设备 bearer；不接受任意地址、路径或查询参数。每次下载核对当前设备、绑定、项目运行状态、租约、审核来源及账号发布规则，再交付与清单摘要一致的实际字节。响应 no-store、nosniff、ETag。

只交付单帧 PNG/JPEG，单图最多 20,000,000 bytes、25,000,000 像素，并完整解码。Pillow 进程处于宽松截断图片模式时返回 503，避免未完整解码的图片进入交付。原生模块分别控制素材数量及总量；不从外部 URL 临时下载图片。

## 2026-10-12 用户确认的目标流程

本节记录后续产品目标，保留以上历史验收事实，不改变当前执行器、审核门禁或自动提交开关。

稿件完成后进入客户已配置渠道的发布队列。顾问按客户实际情况选择渠道、绑定账号和设置发布策略；官网、公众号等均不是默认向所有客户开放。排队与取得发布资格分开：稿件可以待审核、待适配或待授权，执行前必须满足项目既有审核、当前账号权限、内容版本和渠道能力条件。不要求顾问为每个正常任务重复启动自动化。

AI依据实际渠道规则、账号状态和历史结果，在已授权时段、日上限、最小间隔等边界内安排发布计划。确定性的调度器重新校验规则、账号占用、授权及项目状态后，调用已验收的渠道执行器；不接受AI自行新增账号、扩大客户范围、使用任意发布工具或放宽平台规则。A官方API与B浏览器适配只是执行方式，不决定客户的渠道组合或自动化程度。节奏控制可以减少集中操作，但不能保证不会触发平台风控。

多号通保持独立新媒体运营工具的定位，SEO/GEO按需调用发布能力。官网发布接口按原要求继续预留；SEM AI接管仍最后推进且保持关闭。

### 选择渠道时展示实际能力

| 展示模式 | 启用条件与实际含义 |
| --- | --- |
| 全自动 | 当前账号、内容类型与通路已经完成包含正式发布和结果确认的实页验收；项目授权开启后可自动完成正常任务，异常仍可转人工 |
| 半自动 | 明确列出已验收的自动步骤及需要顾问操作的步骤，例如自动填稿和上传、人工最终发布 |
| 人工发布 | 系统负责排队、素材交付及记录，顾问执行发布并提供结果，独立标注是否已经核验 |
| 未接入 / 待验收 / 未授权 | 显示原因和所缺条件，不能执行，也不能以半自动或全自动标识代替验收 |

能力按渠道、账号实际权限及内容类型计算，取能够可靠完成的范围；登录成功、页面能打开和合成DOM测试均不能证明已具备正式发布能力。全自动模式发生一次异常只改变受影响任务或账号的运行状态，不自动将整个渠道永久改成人工模式。

### 顾问介入与恢复

遇验证码、登录失效、平台限制、页面结构变化、上传失败或发布结果不明时，暂停受影响任务或账号通路，记录原因并通知有权处理的顾问。其他无依赖且符合规则的账号可继续执行。验证码由人完成，不能由AI绕过；需要手动发布时交付固定稿件、账号与素材顺序。

人工处理后先重新验证账号、项目授权、内容版本、已发布情况及实际平台状态，再恢复队列。结果不明时保留占用并核查，不能因超时或恢复操作再次提交同一稿件。人工发布回执也不得绕过公开作品与内容核验。

顾问查看排队、等待发布时间、执行中、待人工介入、失败及已发布状态，并能开始、暂停、恢复、结束项目和处理单项任务。日志包含所属客户/项目/账号/渠道、内容版本、计划与实际时间、AI安排理由、失败原因、人工处理及发布回执；不记录凭证、Cookie或带认证查询的URL。发布成功、公开可访问、搜索收录、排名/引流与GEO引用分别展示。

### 当前实现差距

已验证的本地候选包含范围绑定、节奏限制、账号占用、人工交接、核查历史、发布回写与后续观察；这些测试不能替代真实平台发布。当前执行器自动正式提交仍关闭，独立公众号接入的稳定身份、编辑器、上传和正式发布均未验收。后续需要补齐按客户配置的渠道选择与能力展示、达到发布条件后的自动入队/派发、AI在规则内排程、逐渠道执行适配及顾问介入后的可靠恢复。尚未接入的渠道不得标为可自动发布。
