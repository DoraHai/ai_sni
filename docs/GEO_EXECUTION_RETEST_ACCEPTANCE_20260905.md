# GEO 异步隔离与内容复测闭环验收

## 本次范围

- 编辑器异步操作捕获客户、任务和页面生命周期。所有等待结果在写回前校验上下文；旧请求的异常与 finally 不再覆盖新页面状态。
- 覆盖正文、Brief、AI 建议、评分、优化、事实关联、渠道稿、发布回填及后台作业轮询。切换上下文清空客户专属表单；卸载时清除自动保存定时器并停止页面轮询，后台已提交的作业保持原有行为。
- 执行待办可以关联同客户、同问题的内容任务，登记修改说明、修改前与复测快照，保存证据副本和内容版本编号，并显示按引擎分组的品牌提及率变化。
- 前后样本不得重复；仅接受真实 API、v2 方法、判读完成且未标记引用错误的样本。复测需晚于修改前样本及当前内容版本保存时间，修改前样本不能晚于该版本。每个引擎前后至少 3 条才展示该引擎差值；所有引擎满足门槛才按引擎等权汇总。
- 比较仅描述所选样本，不证明内容修改的因果效果，也不自动验收工单。复测编号暂由用户选取填写；不自动发起付费采样或发布内容。

## 数据与隔离

复用 geo_action_tickets 的 content_task_id、baseline_snapshot、progress 和 evidence；无需数据库迁移。仅 workqueue:v1 工单可以调用新关联接口，使用现有客户权限和工单行锁。旧诊断工单、SEM 服务及其页面不在改动范围内。

关联证据保存当时的原文、引用和判读数据副本。重新保存会替换当前关联结果；处理历史仍遵循已有最近 6 条的保留规则，不是无限审计日志。

## 本地验证

- Python GEO 全量测试加 metric_service：540 项通过。
- Node GEO 前端回归：47 项通过，含 10 类实际异步函数的延迟响应场景、手动/自动正文保存及停止轮询。
- 独立 GEO 前端生产构建通过；保留既有主包体积提示。
- 浏览器使用本地内存 API，创建待办与内容任务，保存修改说明及前后快照，显示证据链接和对比，验证无效编号保留输入。
- 浏览器暂停客户 A 正文保存，切换客户 B 后释放响应，确认 A 标题/正文没有回到 B 页面。
- 未调用真实模型、未发布客户内容。本地数据库交互测试使用隔离替身，不等同于 PostgreSQL 并发压测。生产验证应检查版本、GEO 健康、鉴权与新路由，同时核对 sem-backend 进程未重启。
