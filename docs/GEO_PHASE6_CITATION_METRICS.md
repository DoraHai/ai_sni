# GEO 第六批：信源统计口径修正

日期：2026-09-05。未提交、推送或部署。

## 本批修正

- citation-insights 未传时间时默认最近 14 个上海日历日；仅传结束日期时向前推窗口，起始晚于结束返回 400。
- 信源统计默认排除模拟，包括遗留备注中的模拟标记；返回排除数、样本构成和实际窗口。机会清单仍从原始窗口集合计算，保留完整排除原因。
- API/人工/历史样本构成在信源页披露；方法混用或判读待复核时隐藏相关百分比及热图，保留计数。人工及历史样本仍保留在信源统计，新机会清单的资格更严格，页面说明差异。
- 修正热图将总次数平均分配给所有引擎的问题：后端按快照、域名、引擎实际计数；热图每列分母为该引擎全部域名引用次数，不因只显示前六个渠道而缩小分母。旧响应缺少 engine_counts 时不再虚构分布。
- 将「被 AI 引用最多的文章」更名为「被引用域名与样例页面」，避免把域名聚合次数当作单篇文章次数。

## 验证及边界

- 496 项 Python 回归通过，10 项 GEO 前端检查通过，GEO 独立构建和差异空白检查通过。
- 新增验证模拟排除与机会排除计数一致性、混合方法隐藏率、逐引擎计数、非法日期窗口、热图真实分布和全渠道分母。
- 本批只修改 GEO 信源接口、页面、工具及测试；未改共享模型或迁移。
- 旧概览/渠道页也调用此接口，其信源数据会同步采用排除模拟的口径；未传时间的调用不再返回全时段数据。
- 日聚合、交付包等其他旧指标路径尚未全面统一；真实 PostgreSQL 并发和登录浏览器端到端验收仍未完成。构建仍有既有大包提示。
