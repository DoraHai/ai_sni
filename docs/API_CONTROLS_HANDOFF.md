# API 管理、预算与审计（2026-10-10）

范围：超管独立管理页；SEM、SEO、GEO 已计量服务商的新请求。客户工作台权限、百度资金写回保护不变。

## 数据库与启用顺序

1. 人工审核 `scripts/api_controls_schema.sql` 和 `scripts/api_controls_permissions.sql`。
2. 以现有对象所有者执行增量结构与对象权限。四张新表、一项可空预算预留字段；不修改客户、账号或历史单价。运行角色无新表 DELETE，审计只有 SELECT/INSERT。
3. 通过现有各模块发布流程上线代码，保持 `API_CONTROLS_ENABLED` 关闭。
4. 核对三个进程共享 JWT/HMAC 盐与现有 AES-GCM 主密钥（只报告一致性，不输出内容）。备份环境配置，然后在 SEM/SEO 公用配置、GEO 配置设 `API_CONTROLS_ENABLED=true`，逐个重启并健康检查。
5. 以命名全局超管核对登记、费用与 API 页一致、客户和匿名用户拒绝访问。没有默认预算、禁用接口或密钥替换；正式单价使用已有审核单价，其他单价由管理员按合同填写。

失败处理：通过原发布流程回滚应用；关闭功能开关保持旧费用计量。新增表不需删除。不要重复运行非幂等结构脚本，不要给运行角色 CREATE 权限。

## 管理能力

- `POST /api/v1/admin/console/controls`：必须命名全局账号，同时拥有客户与账号编辑权限；实时鉴权。固定动作 budget/provider/rate/credential/connection，UUID 幂等、乐观版本、事务内审计。
- 平台、客户、账号日/月请求及人民币估算金额预算同时生效，时区 Asia/Shanghai；提醒阈值可设置。
- 发请求前在独立事务内检查并预留额度；跨服务以同一 PostgreSQL 事务锁串行准入。拒绝请求不计为服务商调用。
- 金额预算：按次接口预留单次价；文本模型预留整个计价输入档位及输出上限，未提供输出上限时设 4096。无法确定输入范围、流式/多模态、缺少单价、历史未知费用时拒绝；未完成、超时或缺少用量保留预留占用。保守估算控制不等于服务商账单硬保证。未设置金额预算不改变请求输出参数。
- 预留可能比实际 Token 费用大，成功取得完整用量后用估算金额替代。未知价格/用量不当作零，暂不提供人工抹除历史费用或释放未知占用操作。
- 价格按精确域名+模型/接口名匹配，仅人民币。变更生成单价版本并影响后续请求，历史单价冻结。
- 服务商开关拦截后续请求，已有请求正常完成。配置按请求读库，无进程缓存，不需重启。
- 已登记服务器密钥支持在线替换及恢复原配置，同一密钥+域名绑定跨模块生效；AES-GCM 加密、不回显、不写入审计。注册状态仅说明已配置，不代表付费连通测试。百度 OAuth 授权沿用原流程。更换服务器环境原密钥后绑定变化，需要重新设置覆盖值。
- 审计覆盖预算、单价、接口开关、密钥设置、告警处理和账号/角色变更；其他业务操作继续接入。管理未启用期间明确显示待启用，不追补旧记录。

## 验证

原生 PostgreSQL 自有临时 schema：并发限额、平台/客户/账号层级、未知单价/历史未知费用拦截、密钥密文与不回显、幂等/版本冲突、历史单价冻结、审计事务；无真实付费请求。

浏览器：管理表单、新鲜权限检查、身份切换取消请求、密钥字段清空、调用和费用统一；客户入口和原导航保留。
