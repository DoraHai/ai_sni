# GEO 第七批：日聚合与当前交付报告口径

日期：2026-09-05。未提交、推送、部署或操作真实数据库。

## 本批完成

- 日聚合统一识别并排除模拟来源，覆盖租户、业务、单元、问题、未分类及引擎切片；方法混用或待复核时保留计数，隐藏品牌、首位、点名与竞品百分比。
- 当天重算会将已不存在的旧切片归零，避免快照删除、改归属或改成模拟后遗留旧数值。没有删除历史行或新增迁移。
- 当前生成的交付摘要、日序列和切片使用同一批已筛选窗口快照；不再从 GeoDailyMetric 缓存表拼接可能采用旧口径的日序列。
- 交付日序列按上海日历日分桶；已出现的业务/单元切片补齐观察窗空白日，空白日计数为 0、比率为 null。
- 交付业务/单元切片只采用全引擎汇总，不再把同日某个 @engine 行误选为业务总计。切片仍展示窗口最后一天的值，不是全窗口累加值。
- 整个窗口混用方法或含待复核判读时，交付日序列及切片百分比一起隐藏，避免逐日分别合格却跨方法误比。
