# 国内内容分发改造（本地开发版）

2026-09-05。所有变更未暂存、未提交、未推送、未部署。本轮无数据库结构变更。

## 调研依据与结论

- [易媒助手官网](https://yimeizhushou.com/)：公开介绍多账号管理、图文/文章批量发布、定时发布与数据统计；其帮助入口为 https://yimeizhushou.com/help.html 。
- [蚁小二官网](https://www.yixiaoer.cn/)：公开介绍多平台账号、图文文章发布、公众号专属分发，以及浏览器 RPA、云发布等执行方式。
- 官方入口核验：[头条号](https://mp.toutiao.com/)、[搜狐号](https://mp.sohu.com/)、[小红书创作平台](https://creator.xiaohongshu.com/)。其他入口在代码中作为官方后台导航使用，登录后的编辑器尚未实测。
- [Chrome activeTab](https://developer.chrome.com/docs/extensions/develop/concepts/activeTab) 与 [scripting](https://developer.chrome.com/docs/extensions/reference/api/scripting)：用户操作扩展后，按需向当前标签页注入填稿函数，无需申请所有网站的常驻读取权限。

国内分发产品的核心是账号、平台专属稿、执行工具和状态回收。仅列出 WordPress/Ghost 接口或把创建任务标成发布成功，不满足该流程。竞品功能来自其官方公开介绍，本轮没有登录其付费产品或验证其宣传的成功率。

## 本轮实现

- 默认展示国内渠道，自有网站单独筛选，保留已有 WordPress/Ghost 连接。
- 新增百家号、头条号、搜狐号、网易号、企鹅号及公众号浏览器渠道；将小红书和微博开放为浏览器辅助渠道。原公众号官方接口仍保留。
- 支持每个平台多个账号备注。浏览器渠道的“已配置”只表示工作台已登记，明确显示“待浏览器核对”，不假装已授权或已登录。
- 平台专属稿按国内内容场景提供风格和标题编辑建议。短笔记长文、缺少图片、外链及部分承诺用语会在预检提示；这些是产品提示，不是平台审核结论或完整合规审查。
- 从待人工确认任务批量或单篇导出填稿任务包，最多 50 条 / 2 MB。包保留任务、账号标签、标题、正文、原稿版本；不含登录凭据。
- 页面提供可下载的 Chrome/Edge Manifest V3 扩展。导入任务，打开官方后台，核对账号，分别填入标题/正文。
- 扩展通过官方域名白名单、空白编辑区检查、唯一目标识别和原生输入事件填稿；已有内容不覆盖。拒绝跨平台任务、含凭据 URL、重复任务、超大包和不支持的编辑区。
- 内容按纯文本填入，图片需在官方后台上传；原交接台保留富文本复制。只插入文本，不执行稿件中的 HTML/脚本。
- 扩展使用 session 存储，浏览器关闭或手动清除时移除任务；不读取密码、Cookie，不调用私有发布接口，不点击保存/发布。
- 继续使用已有审核、幂等发布任务、人工回填链接验证与分发记录。不把填稿动作自动登记为已发布。
- 客户、网站或用户切换会清空旧记录和交接台；过期加载结果不能覆盖新范围，也不能导出旧范围任务。

## 安装与操作

在分发中心点击“浏览器填稿助手”下载 ZIP，解压后在 chrome://extensions 或 edge://extensions 加载已解压扩展。先生成分发任务，在发布任务页导出 JSON 并导入助手。打开目标平台，登录后进入编辑器，核对账号再填入。完成图片、分类、声明、正文检查并自行发布后，把公开链接回填至交接台。

任务文件包含文章正文和账号备注；不使用外部打包服务。应由有内容编辑权限的操作员导出，按客户保管。平台编辑器无法识别、跨域框架、已有草稿等情况下使用交接台复制粘贴，不能通过覆盖或点击未知按钮强行继续。
