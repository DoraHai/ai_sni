# 国内内容分发改造（本地开发版）

2026-09-05。第一版已随 PR #317 发布；下文记录第一版能力。本次继续补齐半自动分发回收和外链发现，验收记录见文末。

## 调研依据与结论

- [易媒助手官网](https://yimeizhushou.com/)：公开介绍多账号管理、图文/文章批量发布、定时发布与数据统计；其帮助入口为 https://yimeizhushou.com/help.html 。
- [蚁小二官网](https://www.yixiaoer.cn/)：公开介绍多平台账号、图文文章发布、公众号专属分发，以及浏览器 RPA、云发布等执行方式。
- 官方入口核验：[头条号](https://mp.toutiao.com/)、[搜狐号](https://mp.sohu.com/)、[小红书创作平台](https://creator.xiaohongshu.com/)。其他入口在代码中作为官方后台导航使用，登录后的编辑器尚未实测。
- [Chrome activeTab](https://developer.chrome.com/docs/extensions/develop/concepts/activeTab) 与 [scripting](https://developer.chrome.com/docs/extensions/reference/api/scripting)：用户操作扩展后，按需向当前标签页注入填稿函数，无需申请所有网站的常驻读取权限。

国内分发产品的核心是账号、平台专属稿、执行工具和状态回收。仅列出 WordPress/Ghost 接口或把创建任务标成发布成功，不满足该流程。竞品功能来自其官方公开介绍，本轮没有登录其付费产品或验证其宣传的成功率。

## 本轮实现

- 默认展示国内渠道，自有网站单独筛选，保留已有 WordPress/Ghost 连接。
- 新增百家号、头条号、搜狐号、网易号、企鹅号及公众号浏览器渠道；将小红书和微博开放为浏览器辅助渠道。原公众号官方接口仍保留。
- 支持每个平台多个账号备注。浏览器渠道的“已配置”只表示工作台已登记，明确显示“待浏览器核对”，不假装已授权或已登录。
- 平台专属稿按国内内容场景提供风格和标题编辑建议。短笔记长文、缺少图片、外链及部分承诺用语会在预检提示；这些是产品提示，不是平台审核结论或完整合规审查。
- 从待人工确认任务批量或单篇导出填稿任务包，最多 50 条 / 2 MB。包保留任务、账号标签、标题、正文、原稿版本；不含登录凭据。
- 页面提供可下载的 Chrome/Edge Manifest V3 扩展。导入任务，打开官方后台，核对账号，分别填入标题/正文。
- 扩展通过官方域名白名单、空白编辑区检查、唯一目标识别和原生输入事件填稿；已有内容不覆盖。拒绝跨平台任务、含凭据 URL、重复任务、超大包和不支持的编辑区。
- 内容按纯文本填入，图片需在官方后台上传；原交接台保留富文本复制。只插入文本，不执行稿件中的 HTML/脚本。
- 扩展使用 session 存储，浏览器关闭或手动清除时移除任务；不读取密码、Cookie，不调用私有发布接口，不点击保存/发布。
- 继续使用已有审核、幂等发布任务、人工回填链接登记与分发记录。不把填稿动作自动登记为已发布。
- 客户、网站或用户切换会清空旧记录和交接台；过期加载结果不能覆盖新范围，也不能导出旧范围任务。

## 安装与操作

在分发中心点击“浏览器填稿助手”下载 ZIP，解压后在 chrome://extensions 或 edge://extensions 加载已解压扩展。先生成分发任务，在发布任务页导出 JSON 并导入助手。打开目标平台，登录后进入编辑器，核对账号再填入。完成图片、分类、声明、正文检查并自行发布后，把公开链接回填至交接台。

任务文件包含文章正文和账号备注；不使用外部打包服务。应由有内容编辑权限的操作员导出，按客户保管。平台编辑器无法识别、跨域框架、已有草稿等情况下使用交接台复制粘贴，不能通过覆盖或点击未知按钮强行继续。

## 第二版：半自动分发与外链闭环

- 助手 0.2：任务与进度保存在本机扩展 storage.local，显式清除时移除；导入新任务会替换旧任务与结果。任务包仍不含登录凭据。支持复制经过白名单清洗的图文 HTML（保留远程图片引用），平台是否接受图片需核对；没有自动上传图片的能力。
- 平台发布后，可在助手采集当前公开文章 URL，经操作员核对后保存并跳到下一条未完成任务。导出结果 JSON，在分发中心预览并批量回收。任务 ID、平台、原稿版本必须匹配当前网站记录；回收不会再次调用平台发布接口。后端复核任务版本。
- 修复分发列表错误地仅显示前 200 篇内容对应的发布记录。发布记录接口已按网站隔离，不应再次被内容下拉框的分页截断。
- 外链工作台支持批量扫描用户给出的来源页面，或扫描最近分发页面，每批最多 50 页、逐条执行、可看到成功和失败明细。只从真实 HTTP(S) a[href] 提取指向当前网站的链接，去重入库；不把普通提及或站内链接计为外链。
- 记录锚文本、rel（nofollow/ugc/sponsored 等）、抓取时间、HTTP 状态、错误类型，以及最近 20 次证据。首次录入显示待核验；无法抓取或登录挑战不会增加丢失次数。两次未发现需相隔至少 20 小时，避免重复点击误报丢失。发现链接后恢复 active。
- 提供搜索、状态筛选、CSV 导出、批量核验、停止与恢复监控。停止监控不向搜索引擎提交 disavow。权威度/风险评分仍是人工录入，未接入外部评分源，不宣称为自动测量。
- 新增每小时一次的分发页面发现任务，每轮最多 20 条，优先未扫描的记录，正常记录 7 天后重查，抓取失败记录 1 小时后重试；本网站发布记录跳过网络抓取并标记为站内发布；沿用每日已有外链核验任务。限制在有效 SEO 租户和当前网站，抓取走现有公网地址固定与 SSRF 防护，单页总时限 22 秒。
- 新增迁移 0091，为 seo_backlinks.verification 和 seo_content_publications.link_discovery 添加可空 JSONB；不删除或重写历史记录，不涉及 SEM/GEO 数据表。

### 能力边界与后续路线

全网反链检索需要覆盖该市场的数据源；自动发现支持分发记录、用户提供的来源页和下述可选供应商索引，不能宣称是全网外链总量。竞品反链、外链合作机会和自动来源评分尚未提供。没有公开账号登录环境的情况下，真实平台编辑器/富文本兼容性仍不能以模拟测试替代。

公众号原有官方草稿/发布接口保留。头条开放平台的[内容发布方案](https://open.douyin.com/platform/resource/docs/ability/content-management/toutiao-publish-solution)明确限制为视频，不支持头条文章；不能借视频接口宣称实现文章自动发布。半自动阶段以操作员登录、核对账号、处理平台必填项和最终提交为实际流程；未来按平台增加有凭据和结果核验的执行适配器，不改变任务与结果回收协议。

## 数据入口、分析与配图交接补齐

- 外链清单支持 CSV 预览、错误行定位、批量导入及去重，每批最多 500 行、2 MB，兼容 UTF-8、GB18030 和带 BOM 的 UTF-16。支持中文模板与常见供应商列名，来源必须为站外页面、目标必须属于当前网站。有错误时整批拒绝写入；已有记录及暂停监控状态不被覆盖。导入记录保持待核验。
- 可选 DataForSEO Backlinks API 索引查询使用固定官方地址。启用 `SEO_BACKLINK_INDEX_ENABLED=true` 并配置现有 `SEO_DATAFORSEO_LOGIN` / `SEO_DATAFORSEO_PASSWORD`；账号必须有 Backlinks 权限及余额。默认关闭，不自动启用付费服务。每个网站滚动 24 小时最多发起一次请求，失败或结果不确定同样占用次数，不自动重试；单次最多 100 条，每个来源域名一条。索引覆盖取决于供应商，不能保证国内平台完整覆盖。
- 展示来源域名、锚文本、目标页面、链接属性、来源集中度和近 30 天新增/丢失变化。新增按实际首次发现时间统计；丢失只统计本版本开始保存的状态变化事件，不补造历史。分析包含待核验资产，确认数和待核验数分开显示。
- 分发交接台可下载正文与配图 ZIP，包括离线 HTML、纯文本、图片和逐图清单。图片下载沿用公网校验和固定地址防护，支持 JPG/PNG，单图 3 MB、合计 12 MB，最多处理 20 个配图位置，总下载时间 22 秒。缺失图片用正文占位及清单原因标明，仍可下载其余材料。任务版本过期拒绝导出。
- 配图材料供操作员在平台上传；浏览器填稿、公开链接回收和已有官方接口继续使用。未实现无人值守发布，也不把材料下载等同于图片自动上传。

验证覆盖 CSV 编码/边界/站点归属、索引失败与并发防重、素材清洗与部分失败，以及切换客户时丢弃旧响应。供应商请求和图片网络响应使用模拟数据，没有调用真实付费索引或发布真实文章。本轮本地浏览器已能访问正式构建，核对数据入口、禁用的未配置查询按钮及分析页签切换。

最终回归：隔离的新建 PostgreSQL 数据库下后端 749 项通过，前端 49 项通过，任务中心/诊断/整改检查通过，正式构建及 49 个产物校验通过。完整回归发现并修复 SEO 独立入口漏注册分析页签组件的问题，修复后重新运行全部后端测试和正式构建。没有新增数据库迁移。

## 国内渠道目录收敛

国内版可选目录只显示 12 个半自动渠道与微信公众号官方接口：百家号、头条号、搜狐号、网易号、企鹅号、微信公众号浏览器版、小红书、微博、知乎、CSDN、掘金、简书。移除 WordPress、Ghost 的目录入口和未启用的抖音规划项；历史适配器和发布记录保留兼容，不删除客户数据。这是产品范围调整，不是合规判定。

全部 12 个半自动渠道纳入持续测试：任务包、模拟空编辑区填写、拒绝覆盖和不自动点击发布。模拟编辑器测试不等于真人账号兼容性验收。外链继续支持来源页面扫描、CSV 导入、实际链接核验、定时监控和结构分析；全网索引为可选付费数据源，不声称国内全网覆盖。

## 竞品索引差距与本地执行器试用

外链新增 `GET /backlinks/opportunities` 和 `POST /backlinks/opportunities/query`，复用 SEO 站点及租户权限。请求包含 tenant_id、site_id、competitors（1–3 个域名）。DataForSEO 未配置时拒绝调用；已配置时串行查询我方和竞品，每站最多 100 条、每来源域名一条。每网站 24 小时最多一个批次（最多 4 次付费请求，失败也计数），独立单站查询仍有每日一次额度。没有新增供应商、没有启用生产付费开关。

批次先在 site_settings.backlink_opportunities 持久化预约，再调用供应商；每站结果立即保存，保留 provider、as_of、items、rejected 和失败状态。并发点击、改竞品或改站点域名不会重置批次额度；中断的 running 批次可刷新检查已保存样本，24 小时后才允许再次查询。最终写入时再次检查站点归属、域名、request_id，避免旧结果覆盖新范围。无数据库迁移。

差距按来源主机名比较，排除我方索引样本和当前已核实、仍在监控的资产来源。多个竞品命中的相同主机名合并并保留链接证据。比较未合并不同子域，不是注册域级别全网交集；每站仅为限量样本，未出现不代表不存在。我方查询失败时不生成差距，竞品失败不计为零。我方新资产不会由竞品链接自动生成，候选不计入已获外链数。结果可导出 JSON。

分发助手对话框新增本地执行器 ZIP，内含 Python 脚本、固定版本 Playwright 依赖和使用说明。百家号、头条号、搜狐号共用保守的编辑控件识别流程：本机可见浏览器、账号隔离配置目录、登录后打开编辑器、一次填标题及正文、可选本地 JPG/PNG 文件控件上传、唯一按钮识别保存草稿、显式 --publish 加逐篇确认才执行发布点击。缺失/模糊控件会停止，已有不同内容不覆盖。封面、分类、声明、上传完成、审核及公开链接仍由真人核对，当前不是平台专用编辑器已验收适配。

执行器的本机进度文件在填稿/上传和发布前分别记录尝试，崩溃或超时后不自动重做，减少重复发稿/上传。单进程排他锁、原子 JSON 写入；恢复后在平台核实，公开链接结果可导入现有分发工作台。登录状态不上传服务端。验证使用实际 Chromium 加模拟官方域名页面，没有登录真人账号、没有向平台真实发布。抖音/快手官方 API、无人值守封面分类及自动审核轮询尚未实现。

## 系统回归与故障修复（2026-09-05）

本轮系统测试覆盖独立 PostgreSQL 迁移与全部 SEO 测试、全部 frontend/scripts/test-seo*.mjs、Chromium 模拟编辑器、正式构建和下载包核对，以及生产环境 24 个主要只读接口。首轮原有测试全部通过，新增故障场景复现了执行器浏览器启动失败中断整批、同源内嵌编辑器无法识别、扩展名图片上传控件无法识别和富文本换行误判问题。

修复后单账号启动/关闭失败隔离处理，每任务输出 run-report.json，失败退出码为 1；同源 about:blank/srcdoc 编辑区可填写，跨域和无同源权限沙箱不处理；上传控件同时识别 MIME/扩展名，要求支持本次全部图片；用渲染文本核对富文本换行。新增提交超时前持久化预约、恢复不重复提交、默认模式禁止发布的回归测试。

最终独立数据库完整 SEO 回归 771 项通过（含执行器专项 17 项），前端 66 项通过，正式构建与 49 个产物校验通过。浏览器验证机会分析交互及下载 ZIP 内容与源码一致。生产 24 个只读接口均为 200，未登录请求 401，错误站点租户范围 403；未修改生产数据、未调用付费供应商、未发布真实文章。本轮只修复下载的本地执行器，不变更数据库 Schema。

开发状态：任务 CRUD、指标快照和图片重新抓取核实已实现；外链来源扫描、CSV、核验监控和限量竞品索引比较已实现，外部数据账号尚未配置实测；12 渠道填稿助手及三平台本地执行器处于真人验收前阶段。抖音/快手官方发布、封面分类全自动处理、审核自动回收、多供应商国内覆盖对比仍未完成。
