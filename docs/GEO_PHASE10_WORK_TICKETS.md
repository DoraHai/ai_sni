# GEO 执行待办与验收记录

文章工作台的工作建议现可“加入执行待办”，复用现有 GeoActionTicket 数据表和接口，没有新增迁移。待办保存当时的观察期、原因、动作、验收要求；有目标问题和机会快照时一并记录问题 ID、快照 ID、证据版本。保存内容是工作背景，不是不可篡改的审计证明。

执行状态：待开始、执行中、受阻、重新处理、已验收。可以记录未达标结果，人工通过后保留完成时间及证据记录，支持显示已验收与重新处理。原有验收工单页也能为这类工单输入核验说明。

新工作建议工单使用 workqueue:v1 前缀。加入时按客户锁定并复用同代码未完成工单，避免重复点击或并行创建产生重复记录；没有对所有历史工单及重新打开旧记录实施全局唯一约束。完成后可再次加入同类工作。当前未增加负责人、截止日期、自动验收、变更通知或效果归因。

验收保护：新前缀工单必须填写非空核验结果后才能人工通过/未达标；直接 PATCH status=done 会被拒绝。原有工单无需说明的调用方式保持兼容。人工验收仅表示操作人确认工作完成，不能证明模型效果已提升。

前端读取与写入均对客户变化、重载及组件卸载设置过期响应保护；接口失败保留错误提示，提交失败时保留输入。待办列表与当前观察期独立，旧待办不会因建议或观察期变化而消失。
