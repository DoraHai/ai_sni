## 来源及边界

根据 2026-09-03 对老虎客户已填写业务说明的只读核对，抽象出粉末涂料场景：企业采购、
材料选型与技术咨询为重点，艾仕得和阿克苏诺贝尔是同行竞品。样本使用虚拟客户名，
不保存真实租户 ID、百度 UCID、密钥、原始客户记录或账户统计。

服务地域及非经营范围未确认。交通运输应用不等于经营汽车修补漆，建筑建材应用不等于经营
家装乳胶漆；不得把待确认范围写成确定排除项。工业数码打印油墨也尚未确认，不纳入本轮核心词。

此前线上重评的 20 词以竞品名称变体为主，结果为 19 个 watch、1 个 drop，全部 relevant。
这证明不了模型能区分噪音和无关词。下列 20 词是另外构造的离线验收样本；旧提示词下的一次
真实 qwen-plus 结果见下方记录，不代表生产使用该模型。

## 样本设计

数据文件：`tests/fixtures/sem_expansion_acceptance_v1.json`。

| 分组 | 数量 | 验收预期草案 |
| --- | ---: | --- |
| 采购 / 产品选型 | 4 | relevant；允许 adopt 或 watch，均不代表执行许可 |
| 竞品 / 比较 / 替代 | 4 | relevant；按各词允许 watch 或 drop，不直接 adopt |
| 官网导航 / 信息查询 | 3 | relevant 与投放价值分开；官网 drop，其余 watch 或 drop |
| 通用噪音 | 3 | generic；watch 或 drop，不能输出 AI 出价 |
| 明确无关 | 3 | irrelevant/drop，不能输出 AI 出价 |
| 产品边界 | 3 | allowed_pairs=null，等待业务确认，不纳入分类正确率分母 |

17 个词有草案预期，3 个边界词单列。全部 relevant 的退化策略至少不满足 6 个明确负例。
这些标签是工程验收建议，并非负责人已确认的金标准；业务审核可调整，但应保留调整原因和版本。
模型价格、搜索量、竞争度不能凭空填入样本。测试中的 4 元指导价和 3 元建议价均是合成输入。

## 离线测试实际验证什么

运行：

```text
python -m pytest -q tests/test_sem_expansion_acceptance.py
```

- 20 个唯一词、6 个分组、17/3 评分分界、标签枚举及资料边界完整。
- 生产提示词构造函数只接收画像和候选词，不接收预期标签及解释，避免答案泄漏。
- 使用模拟模型返回值，运行真实 `_evaluate_batch` 解析器；噪音、无关、drop 或缺指导价时隐藏
  AI 出价及理由，相关/watch 不会被强制改为 adopt。
- 测试拒绝 socket 网络连接，并默认拦截模型入口；不创建数据库会话，不执行候选写入流程。
- 模拟返回与网络拦截共用同一清理作用域，每项测试结束后核对入口已恢复，避免污染后续测试。

**测试通过只证明样本及解析保护契约通过，不代表真实 DeepSeek 的 17 个词判对，也不代表
17/17 准确率。** 模拟相关性输出不能验证模型的真实相关性判断。新提示词的真实模型验收未执行。

## 2026-09-03 历史观测与本轮修订

在另行获得一次性调用授权后，用相同虚拟画像与 20 词请求 qwen-plus，仅 1 次、无重试。
输入未包含预期标签、指导价、搜索量或竞争度。按尚未最终批准的草案为 13/17；
3 个范围待确认词不计分类分数。不能将该比例推广为模型准确率或据此更换生产模型。

历史返回转录于 `tests/fixtures/sem_expansion_qwen_observed_20260903.json`，与预期标签文件分开。
保存模型名、时间、旧提示词哈希及 20 项原始结果字段，不保存认证信息；它不是新提示词结果。
后续修改预期标签或画像时，应另建版本，不能覆盖此次输入及历史偏差来提高分数。

本轮仅修改 SEM `app/ai/expansion_eval.py` 的提示词，不修改解析器、API 或资金回写逻辑：

- 按业务依据 → 语义相关性 → 投放建议 → 出价依据依次判断，防止无采购意图被当作行业无关。
- 已知同行的公司信息、官网、技术资料仍区分 relevant 与 watch/drop；未知投放策略不能抹去已知同行关系。
- 未确认策略的竞品替代选型保持 watch，不因出现“替代”自动推荐 adopt。
- 未提及相邻产品不等于排除其经营范围；提示资料待确认，明确跨行业无关词仍可排除。
- 缺指导价时两项报价字段均为 null；不编造搜索量、竞争度或转化表现，JSON 示例也使用 null。

离线回放验证 4 个虚构报价在解析层和 API 输出层均被既有保护清空，不影响人工预设。
**合法格式的语义错误仍会通过解析器。回放测试故意保留这一事实，不硬编码品牌、不篡改返回，
也不把提示词文本断言当作模型质量测试。** 此次只完成规则修订，改善效果仍需真实模型复测。

提示词属于现有画像指纹的一部分；若后续发布，旧结果将标记为 stale，AI 报价不再展示。
不会自动删除、覆盖、回填或重评历史结果；人工显式重评仍遵守每批上限和确认流程。
