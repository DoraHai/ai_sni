# 客户工作台真实AI对话

2026-10-09。新增 POST /api/v1/seo/workbench/assistant/chat，专用于客户工作台。通用SEM assistant接口需要SEM模块授权，不能直接用于SEO-only客户。

请求：tenant_id、site_id、request_id(UUID)、message(1–1000字符)、history(最多12条user/assistant、单条6000、总24000字符)、可选content_id。禁止额外字段和system角色。普通实名账号有seo.content查看资格即可使用；网站、关键词和任务证据按各自view权限筛选。原JWT、模块有效性、客户/站点归属与站点活动状态每次核验；API Key拒绝。演示只读绑定仍拒绝POST。

后端自己读当前站点的稿件/页面/关键词状态统计和最多20条预览、授权任务状态；选定稿件读取最多6000字符，明确版本、截断和未核验确认。请求不能上传伪造指标/业务动作。当前不提供排名数值、流量、确认计数或全站内容全文，模型不得把稿件ready当已确认。来源标签只接受实际提供的证据名称。

复用官方DeepSeek route、chat_json及持久化operation。聊天采用独立额度，不占稿件生成的ai_requests：客户每日100次、账号在该客户内每日30次、每分钟5次；每账号在该客户内最多1个在途回答、每客户最多3个。额度参数在app/config.py中可配置，频率不因失败退款而重置。日额度按Asia/Shanghai午夜恢复。数据库TenantModule行锁保证多进程和多站点并发一致，锁在调用模型前释放。新聊天使用120秒租约，模型45秒超时；过期租约按既有流程退款或在新请求准入时回收。

请求键wb:user_id:UUID、payload包含站点、当前相关查看资格及模型路由；重复请求在限流前取回原结果，运行中409，不重新请求模型。兼容UI19旧结果，旧请求按原共享额度规则退款，新请求退款仅回退聊天客户及账号日额度。结果保留沿用operation30天清理。中断退款未成功时由既有到期对账接续。正式调用必须有已有DEEPSEEK_API_KEY、官方HTTPS端点和允许模型，不向百炼回退。

调用期间不持有业务行锁。返回/取回前重新读取账号、角色、模块和站点资格；失效不返回旧回答。正常完成只写AI调用/额度记录，不写稿件、消息、确认、任务或发布。客户端只接收answer、来源和供应商元信息，不返回或执行模型actions。

对话历史由当前窗口保存并传入滑动窗口，切身份/客户/站点清空，刷新后不自动恢复；这是第一版窗口上下文，不是跨设备聊天记录。工作台规则数据导览保留并明确非AI；稿件顾问消息继续走原人工会话接口。

业务话题覆盖当前客户的网站、SEO、推广策略及稿件。明确索要其他客户数据或系统密钥的请求在读上下文/调用供应商前返回422；其他偏题由模型给出scope判断，out_of_scope时服务端用固定业务引导文案替换回答、清空来源。缺失/非法scope拒绝结果并退款。话题判断是软约束，不能保证所有诱导均被识别；数据隔离、无业务工具、权限复核才是硬边界。NULL客户绑定在现有账号模型中代表全客户权限，本接口拒绝未绑定客户且没有seo.content编辑资格的账号，要求先核对账号客户绑定；全客户内部编辑人员仍每次只读指定的一个客户/站点。此限制在调用前和取回/交付前都检查，不因提问扩大查询范围。本轮只加AI接口门禁，不修改账号绑定或其他业务接口权限。

在供应商输入（问题、历史、所有证据字符串）和持久化/交付回答两端过滤常见API Key、Bearer/JWT、密码赋值、数据库连接凭据、PEM私钥、邮箱、中国大陆手机号、身份证及满足Luhn的银行卡号。不发送模块设置、用户表、内部备注或人工顾问消息。操作记录只存请求指纹，不存原始输入；旧缓存回答取回也过滤。该规则过滤不是完整DLP，任意自定义秘密、姓名/地址和供应商对已发送内容的保留不在保证范围；本轮不追溯修改旧缓存原文。

本地定向后端43项通过（新对话、站点范围、DeepSeek路由、原驾驶舱权限），HTTP MockTransport实际运行既有DeepSeek客户端，无外部调用。前端独立验证多轮、稿件上下文、XSS文本转义、同UUID恢复、503草稿保留、390px全屏、跨客户迟到回答丢弃及403清空。本地夹具不代表正式客户登录验收。

不新增表、不迁移、不改密钥/共享配置。上线顺序：SEO独立审核/发布后确认新接口存在，再发布客户工作台静态包；不得把SEM/API Key会话当普通SEO客户验收。
