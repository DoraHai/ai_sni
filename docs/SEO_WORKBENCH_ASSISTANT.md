# 客户工作台真实AI对话

2026-10-09。新增 POST /api/v1/seo/workbench/assistant/chat，专用于客户工作台。通用SEM assistant接口需要SEM模块授权，不能直接用于SEO-only客户。

请求：tenant_id、site_id、request_id(UUID)、message(1–1000字符)、history(最多12条user/assistant、单条6000、总24000字符)、可选content_id。禁止额外字段和system角色。普通实名账号有seo.content查看资格即可使用；网站、关键词和任务证据按各自view权限筛选。原JWT、模块有效性、客户/站点归属与站点活动状态每次核验；API Key拒绝。演示只读绑定仍拒绝POST。

后端自己读当前站点的稿件/页面/关键词状态统计和最多20条预览、授权任务状态；选定稿件读取最多6000字符，明确版本、截断和未核验确认。请求不能上传伪造指标/业务动作。当前不提供排名数值、流量、确认计数或全站内容全文，模型不得把稿件ready当已确认。来源标签只接受实际提供的证据名称。

复用官方DeepSeek route、chat_json和SEO AI每日限额/持久化operation。请求键wb:user_id:UUID、payload包含站点、当前相关查看资格及模型路由；重复请求只取原结果，运行中409，不重新请求模型。结果保留沿用operation30天清理。失败退款；中断退款未成功时由既有到期对账接续。正式调用必须有已有DEEPSEEK_API_KEY、官方HTTPS端点和允许模型，不向百炼回退。

调用期间不持有业务行锁。返回/取回前重新读取账号、角色、模块和站点资格；失效不返回旧回答。正常完成只写AI调用/额度记录，不写稿件、消息、确认、任务或发布。客户端只接收answer、来源和供应商元信息，不返回或执行模型actions。

对话历史由当前窗口保存并传入滑动窗口，切身份/客户/站点清空，刷新后不自动恢复；这是第一版窗口上下文，不是跨设备聊天记录。工作台规则数据导览保留并明确非AI；稿件顾问消息继续走原人工会话接口。

本地定向后端43项通过（新对话、站点范围、DeepSeek路由、原驾驶舱权限），HTTP MockTransport实际运行既有DeepSeek客户端，无外部调用。前端独立验证多轮、稿件上下文、XSS文本转义、同UUID恢复、503草稿保留、390px全屏、跨客户迟到回答丢弃及403清空。本地夹具不代表正式客户登录验收。

不新增表、不迁移、不改密钥/共享配置。上线顺序：SEO独立审核/发布后确认新接口存在，再发布客户工作台静态包；不得把SEM/API Key会话当普通SEO客户验收。
