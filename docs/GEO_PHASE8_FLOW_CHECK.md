# GEO 第八批：接口串联及页面保存检查

日期：2026-09-05。未提交、推送或部署，未连接生产数据库或调用真实模型。

## 发现并修复

- **交付任务日期与快照日期不一致。** 原先直接比较 UTC 任务时间和日期零点，结束日期当天任务可能漏算。现在统一按上海日历日起止转换为 UTC，采用左闭右开区间；带时区任务时间先转换为 UTC。
- **普通 Markdown 导出可能报错。** 关闭期次分支内部的 PlainTextResponse 导入遮蔽同名全局变量，普通分支未执行导入即引用。移除局部导入，普通/固化两条导出路径均有覆盖。
- **简报保存迟到响应可能覆盖当前任务。** 保存时捕获客户、任务和加载代次，仅在它们仍匹配时应用结果或错误提示。缺少客户/任务时也递增加载代次并清空任务，避免接收旧加载结果。

## 实际验证

- 新增接口函数串联测试：citation-insights → 创建机会任务 → 重复创建返回已有任务 → 编辑简报保留来源 → JSON 交付 → Markdown 导出。
- 后续同题样本增加时，报告样本数更新、原任务来源数量保持创建时记录。
- 验证摘要/日序列/业务汇总样本数一致，业务行不误取某个引擎；混合方法的百分比一致隐藏。
- 验证上海日开始、当天 23:59:59、次日 00:00 边界，以及错误客户在存储读取前被拒绝。
- 验证关闭期次仍返回固化结果，不重算历史交付物。
- Node 测试执行实际组件的 saveBrief 函数，使用受控 ref 和延迟响应覆盖跨客户/任务切换、同任务重新加载、正常保存三种情况。

- 506 项 Python 测试通过，无跳过；13 项 GEO 前端检查通过；独立 GEO 构建通过；差异空白检查通过。
- 接口串联测试使用内存存储替身；执行真实路由函数、过滤/聚合/导出逻辑，但不经 HTTP 中间件或真实 SQL 数据库。任务更新返回的详情和无关事实/文章读取被替代。
- 前端测试没有挂载 Vue 页面或操作真实浏览器。页面跳转进行了代码检查；浏览器实际点击、真实登录态和真实 PostgreSQL 并发仍未完成验收。
