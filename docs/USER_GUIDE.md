# Growth Sniper 模块使用说明

面向运营和交付：按左侧菜单说明每个模块做什么、先点哪里、数据从哪来、常见误判怎么避。

**按客户从开户写到对外汇报的详细操作**见 [`GEO_OPERATOR_GUIDE.md`](GEO_OPERATOR_GUIDE.md)（事实核验、禁止编造、竞品三栏、样本门槛）。  
**含现成测试数据的点击链路**见 [`GEO_CLICK_TEST_CHAIN.md`](GEO_CLICK_TEST_CHAIN.md)（Udesk优地门禁 + 智齿完整环）。  
工程实现与指标公式见 `docs/GEO_METRIC_DICTIONARY.md`；本地联调端口见 `docs/LOCAL_GEO_DEMO.md`。

产品分两条线，**不要混在一个客户里测**：

| 产品线 | 侧栏入口 | 解决什么 |
| --- | --- | --- |
| **GEO 增长** | GEO 增长 | AI 搜/问场景里，品牌有没有被提到、有没有被引用；缺了就写内容、发出去、再测 |
| **SEM 投放** | 首次接入 / 每日盯盘 / 优化执行 / 效果验证 / 投放管理 | 百度搜索广告：同步账户、盯消耗与质量、拓词否词、调价验证 |

顶栏可切换**客户**（租户）。所有 GEO / SEM 业务数据都按客户隔离。本地开发用 API Key 时，默认会落在某个租户上，开新品牌请先「新建客户」再开户。

顶栏**观察期**（近 7 / 14 / 30 / 90 天）是上海日历日，影响概览、可见度、引用、期次对比、话题热度等报表。没有样本时指标应显示「—」，不是 0%。

## 推荐工作顺序

### GEO 闭环（新客户）

1. **系统设置 → 账号与权限**：新建客户（建议同时建管理员账号）。  
2. 顶栏切到该客户。  
3. **GEO 开户向导**：填可访问的官网 URL，预览后确认写入。  
4. **事实库**：核验至少 3 条事实。  
5. **优化意图词**：品类题不带品牌；带品牌的标成「探测题」。  
6. **引擎配置 / AI 配置**：监测定位保持 hybrid；真采样需配 Key。  
7. **全自动巡检**：先小规模跑通，再看概览 / 可见度 / 缺口。  
8. **缺口工作台** → **优化文章**：策略、绑事实、生成母稿、出渠道稿、审核、登记发布 URL。  
9. 再巡检，看任务「发布后效果」、期次和交付摘要。

### SEM 闭环（已有百度账户）

1. **授权与同步**：绑定账户并拉计划/关键词。  
2. **数据看板 / 异常提醒**：看消耗、转化、质量度异常。  
3. **拓词 / 关键词工作台 / 否词**：扩词入库、调价、加否词。  
4. **调价台账 / 待验证调价**：验证调价是否带来效果。  
5. **分析报告**：对外交付。

## 系统设置

### 账号与权限 `/settings/accounts`

**做什么**：建客户、建登录账号、配角色菜单权限。

**客户 ≠ 账号**

- 「新建客户」只创建租户（名称、品牌词、行业）。  
- 本页上方是**已建客户**列表，可切到该客户。  
- 下方「账号」表只列登录用户。本地只用 API Key、没填管理员账号时，账号表为空是正常的。  
- 新客户是空壳：旧客户的业务、意图词、快照**不会**拷过来。

**建议操作**

1. 新建客户时填写品牌词（如：智齿科技, 智齿, zhichi）和行业。  
2. 需要登录隔离时，同时填管理员账号（密码至少 8 位），或事后「新建账号」并限定到该客户。  
3. 角色可按菜单设「无 / 可见 / 可编辑」。「管理员」必须保留账号与权限的编辑权。

**注意**：绑定了单客户的账号不能再建客户，也不能看别的客户数据。

## GEO：内容生产

### GEO 开户向导 `/geo/onboarding`

**做什么**：官网 URL → 业务线、意图词、事实草稿、引擎建议；确认后写入。

**步骤**

1. 填写公网可访问的 `https://` 官网（要 HTTP 200）。虚构域名会抓取失败。  
2. 建议打开「百度下拉扩展」（稍慢，词更接近真实问法）。  
3. 预览后核对：  
   - **业务线**：去掉标题切开的碎片（如单独的「AI」）。  
   - **意图词**：优先勾「品类可见度」（不带品牌名）；「探测题」少勾。  
   - **事实卡**：标题可能重复，看正文再勾。  
4. 可先「演练（不写库）」，再「确认写入」。  
5. 写入后按清单补：业务、意图词、已核验事实、引擎、渠道。不要在未配 Key 时自动开定时巡检。

**写入规则**

- 同域名官网渠道会复用；名称「官网」已被占用时建成 `官网 · 域名`。  
- 带品牌名的问句会标 `is_brand_probe`（探测题），不计入品牌提及率。  
- 意图词默认挂到匹配的业务线下的默认单元。

### 优化业务 `/geo/businesses`

**做什么**：维护「业务 → 单元 → 意图词」，看按天切片。

**结构**

| 层级 | 含义 | 例子 |
| --- | --- | --- |
| 业务 | 客户下的产品线 | 智齿客服、化工离心泵 |
| 单元 | 业务下的主题/关键词桶 | 默认单元、选型、价格对比 |
| 意图词 | 真正拿去问 AI 的完整问句 | 在线客服哪个好 |

**操作**

- 点左侧业务，中间出单元，右侧出该单元下的意图词。  
- 开户写入的词通常挂在**有产品名的那条业务**上，不会出现在标题碎片业务里。  
- 页面会优先打开「单元上已有意图词」的业务。  
- 归档是软删除。勾选「显示已归档」可恢复业务/单元。  
- 「业务详情一屏」串：覆盖、缺口、本期任务、监测摘要。

**不要**：把两个无关品牌建在同一客户下，再指望策略和监测自动拆开。

### 优化意图词 `/geo/prompts`

**做什么**：巡检和写稿用的问题清单。

**两类题必须分开**

| 类型 | 例子 | 用途 | 报表 |
| --- | --- | --- | --- |
| 品类可见度 | 企业智能客服哪个好、在线客服对比怎么选 | 用户没点名时 AI 会不会提到你 | 计入**品牌提及率** |
| 探测题 | 智齿科技怎么样、智齿是哪家公司 | 点名后答得准不准、引不引官网 | 只计入**点名认知率** |

**操作**

- 「新建意图词」或「智能推荐」。智能推荐请填**品类词**（智能客服、在线客服），不要只填品牌短词。  
- 编辑里可改问句、挂单元、问题组、优先级，并打开「品牌探测」。  
- 带品牌名的词入库时应显示「探测题」。  
- 未挂单元的词会进日指标 `unc`（未分类）桶，业务切片看不到。

**智能推荐注意**：品牌短词（智齿、泉衡）的百度下拉噪声多（牙膏、招聘、评级）。系统会过滤导航/招聘/股票/拼音等同音噪声，并要求品牌词带业务上下文。

### 缺口工作台 `/geo/gaps`

**做什么**：把「品牌没被提到」的意图词变成任务。

**操作**

1. 先有巡检快照，否则缺口是空的或全是未测。  
2. 按业务/优先级勾选 `brand_missing` 意图词。  
3. 批量建任务，到「优化文章」写稿。  
4. 探测题上的「没提到」没有意义，不要当缺口建任务。

### 事实库 `/geo/facts`

**做什么**：可核验的产品/案例/口径，生成母稿时当证据。

**信任级别**：`draft`（草稿）→ `needs_review`（待核验）→ `verified`（已核验）。  
生成母稿至少绑定 **3 条已核验**事实。来源名称必填。

开户抽到的多条事实标题可能都叫公司名，以**正文**区分。任务编辑器的「当前绑定」会展示正文和来源。

### 优化文章 `/geo/tasks` 与编辑器 `/geo/tasks/:id`

**做什么**：一篇内容从策略到发布的主工作台。

**建议顺序（左侧「当前下一步」）**

1. **内容策略**：行业、受众、意图、内容类型、CTA 必填后保存。  
   - 「AI 建议」按**当前客户**的品牌/行业生成，不是按业务线。客户是泵业、任务写客服时，建议会串台，请手改后再保存。  
   - 策略/事实面板默认保持展开，不会因进入写稿步骤自动收起。  
2. **事实绑定**：一键绑 3 条已核验，或按 Brief 召回后再绑定。列表会显示事实正文。  
3. **生成母稿**：内部草案，不能当正式发布文。可检查就绪、AI 审稿、人工改正文。  
4. **渠道成稿**：勾选官网 / 微信 / 知乎等，点「AI 生成正式渠道稿」。  
   - 勾了 3 个却只出 2 个页签：通常是某渠道未过完整文章门控（如微信「提纲感过重」）。页上会列出失败原因，可「重试失败渠道」。  
   - 微信要求完整段落，不能小标题下只堆要点。  
5. **审校**：提交 → 他人通过/驳回（默认禁止自己审自己）。  
6. **发布**：回填已发 URL，或走 Webhook / 已配置的社交账号推送。登记 URL 后，监测才能把引用对回这篇文章。  
7. **发布后效果**：发布前后窗的提及率与命中的 `matched_publication_ids`。样本不够或含模拟时，页面应写明，而不是空白当 0。

分发推荐（蓝图）按问题组提示优先阵地，例如「推荐」偏官网事实源 + 榜单，不是自动发稿。

### 发布渠道 `/geo/publishing`

**做什么**：登记本客户要发的阵地（官网、微信、知乎、文档站等），以及账号/Webhook。

- `channel_type` 决定编辑器能出哪些成稿页签。未启用的类型不会生成对应稿。  
- `publish_mode`：`manual_only` 只导出；`auto_publish` 可走已配账号。  
- 官网 `base_url` 会进入「自有域」，用于引用归因。

### 媒体阵地 `/geo/placements`

**做什么**：规划「要出现在哪些媒体/平台」，和「已经发布的 URL」不是同一张表。  
用于蓝图优先级、分发推荐，不替代发布回填。

## GEO：效果监测

口径摘要：

| 指标 | 含义 | 注意 |
| --- | --- | --- |
| 品牌提及率 | 品类题里 AI 有没有提到本品 | **排除探测题**；无样本为 — |
| 点名认知率 | 探测题里能不能正确识别本品 | 几乎总会提到品牌，不能当可见度 |
| 首选位率 | 提到时是否排在第一 | 同观察期、同剔除规则 |
| 样本构成 | 真采样 / 模拟 / 人工 | 交付必须展示；模拟不能当真实效果 |

### GEO 概览 `/geo/overview`

看本客户观察期内的提及、缺失、待办。空态会说明是「没意图词 / 没巡检 / 没快照」。不要在 hybrid 下把模拟 100% 提及当成已占领推荐位。

### AI 可见度 `/geo/visibility`

快照明细：意图词 × 引擎 × 是否提及、位置、情感、引用 URL。  
可手工「登记快照」（粘贴回答）。批量请走巡检。

### 全自动巡检 `/geo/visibility/patrol`

**做什么**：按「意图词 × 启用引擎」批量问 AI，并可自动落库快照。

**参数**

- 意图词上限：按优先级取前 N（最多 50）。  
- 引擎：空选则用已启用的。  
- 优先真采样：引擎是 `openai_compat` 且有 Key（或回退租户/环境百炼 Key）。  
- 自动落库：关闭则只出运行明细，不进报表。

**监测定位**（在引擎页设置）

| 定位 | 行为 |
| --- | --- |
| hybrid（默认） | 有 Key 真采样，没有则人设模拟 |
| simulation | 全部模拟 |
| real_only | 没有真 Key 的引擎直接跳过，页面会空 |

**注意**

- 不要在未配 Key 时打开**定时巡检**，会持续灌模拟数据。  
- 日配额默认每客户 24 次。  
- 探测提示里会带「品牌参考名」。品类题若仍 100% 提到本品，先检查是不是提示词把品牌喂给了模型，再看是否真可见。  
- 跑完应能在可见度、概览、缺口同步看到变化。

### 优化期次 `/geo/periods`

给一段优化工作划时间窗（基线 → 期末）。关闭期次后可看前后对比。样本不足会提示，不要当失败。

### 交付摘要 `/geo/deliverables`

对外包装：提及变化、样本构成、期次结论。含模拟时应写明「含模拟 / 尚不能判断」。可生成分享链接。

### AI 引用分析 `/geo/citations`

从快照 `cited_urls` 归集域名、是否自有域、关联意图词。模拟回答常常没有链接，空表不一定是坏了。

### 竞品监测 `/geo/competitors`

**怎么来的**：巡检标注里的 `competitors` 按名字加总，不是你事先维护的竞品库。

| 列 | 含义 |
| --- | --- |
| 出现 | 多少条快照点过这个名字 |
| 来源 | 这些快照里抽出的引用 URL 去重数 |
| 平台 | URL 对上的渠道种数 |
| 提问 | 覆盖多少条不同意图词 |

点「查看来源」：

1. 有引用 URL 时，按链接反推官网/知乎等平台。  
2. **没有 URL** 时，用内置阵地库给出**推定发布位置**（七鱼、Udesk、美洽、容联七陌、小能、Zendesk、环信等），并标明不是本次被点到的具体页面。  
3. **GEO 逆向建议**：按该竞品赢下的提问组给出补官网对比页、知乎问答等，可一键建任务。同一意图词已有未归档任务会跳过。  
4. 仍可手写洞察/行动，生成 Markdown 报告（存在浏览器本地）。

别名：把「七鱼」「网易七鱼」收成一行。

### 评价与位置 `/geo/evaluation`

快照上的情感、品牌位置。点意图词可跳回可见度补标。

### 话题覆盖热度 `/geo/topic-heat`

按「意图词 × 引擎 × 日」去重后的覆盖变化，用来找近期测得多、动得猛的词，**不是**市场搜索热度。  
观察期支持 7/14/30/90 天。

## GEO：能力与情报

### 引擎配置 `/geo/engines`

启用要监测的引擎（DeepSeek、豆包、Kimi、ChatGPT、Perplexity 等），设置采样模式：

- `mock_persona`：用人设模拟该引擎语气（同一后台模型）。  
- `openai_compat`：走兼容接口真采样，需 Key、base_url、model。

此处改**监测定位**（hybrid / simulation / real_only）。

### AI 配置 `/geo/ai-settings`

租户级大模型凭证。默认推荐阿里云百炼 OpenAI 兼容模式。未配租户 Key 时，可用环境变量 `DASHSCOPE_API_KEY` / `DEEPSEEK_API_KEY` 兜底。  
母稿生成、渠道成稿、巡检真采样都走这里。

### 渠道成稿提示词 `/geo/channel-polish-prompts`

覆盖官网/微信/知乎等成稿的系统提示、口吻、最低字数。不达标会整篇驳回（见优化文章）。

### AI 动态与策略 `/geo/ai-trends`

外部引擎/产品动态备忘，辅助调整监测与内容策略，不是本客户可见度数据。

## 诊断中心

### 网站体检 `/diagnostic-center/`

对官网做 GEO 技术体检（结构化数据、可抽取块、爬虫等）。分数偏低时先修 top issues，再铺内容。  
开户预览里也会带一份体检摘要。可以从诊断建议创建内容任务。

### AI 助手 `/assistant`

对话式查询本客户数据与操作建议。切换客户会清当前会话展示。

## SEM：每日盯盘

### 数据看板 `/monitor/dashboard`

消耗、点击、转化、质量度等日报。顶栏切换客户后会重拉。

### 异常提醒 `/monitor/alerts`

规则触发的异常（高消耗低转化、质量度下滑等）。侧栏徽章为未处理数。

### 客户画像 `/monitor/profile`

账户层级的结构与效果画像，辅助判断该不该拓词或收否词。

### 关键词详情 `/monitor/keywords/:id`

从看板或列表下钻，不单独做菜单入口。

## SEM：优化执行

### 拓词 `/optimize/expand`

从词根/URL 出候选，确认后入库。侧栏徽章为待处理候选数。与 GEO「智能意图词推荐」不是同一套词库。

### 关键词工作台 `/optimize/keywords`

看关键词效果、调价、改匹配、停启用。

### 搜索词报告 `/optimize/search-terms`

实际触发的搜索词，决定加否词还是收词。

### 否词管理 `/optimize/negatives`

账户/计划/单元级否词。

## 常见问题

**开户候选词是牙膏/招聘/拼音？**  
品牌短词被搜索下拉带偏。应用页面产品词做根，带品牌的标探测题。刷新预览或用智能推荐填品类词。

**优化业务里意图词是 0？**  
点开挂了词的业务（如「智齿科技」），不要点标题碎片「AI」。

**AI 建议全是另一个行业？**  
策略按客户品牌生成。请为该品牌单独建客户，或手改策略后保存。

**账号页新建客户后没数据？**  
客户已建，账号表是登录用户。GEO 业务要再走开户向导。

**巡检 100% 提及？**  
先看是不是探测题、是不是模拟、探测提示有没有把品牌名喂给模型。

**竞品溯源没有 URL？**  
回答里常没有链接。看「推定发布位置」和逆向建议即可。

**话题热度报 Input ≤ 60？**  
观察期 90 天已与接口对齐；若仍报错，确认后端已更新到含该修复的版本。

**渠道勾了 3 个只出 2 个页签？**  
失败渠道未过完整文章门控，编辑器会列出原因，可单渠道重试。
