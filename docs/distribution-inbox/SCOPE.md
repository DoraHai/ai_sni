# SCOPE（用户 19:45 收窄，优先于方案）
1. **不做平台域名粗检**：所有平台传回来都照收。平台字段原样记录（清洗：去控制字符、长度上限），识别不了的记「其他」，不拦截。链接只做最基本的安全形状：可解析的 http/https 绝对 URL、无账号密码段、长度 ≤ 2048；不按域名/路径拦截。方案里的十类平台规则表、normalizer 测试向量不做。去重用「去掉 fragment、host 小写」的简单规范化即可。
2. **不做 80% 预警**：只保留每个所有者未标注 1000 条 / 10 MiB 硬上限；满了拒收新回传（客户端保留待传，不丢）。
3. **顾问界面只保留三样**：
   - 「生成配对码」按钮（无任何选择，备注可留空自动取名）；
   - 「待标客户」收件箱：每条显示平台、标题、链接、账号名、结果、时间；操作只有选客户（客户同时开通 SEO 和 GEO 时再选 SEO/GEO）；网站/项目、关联稿件等其余可选项默认收起；能改标/撤销（按方案权限）；
   - 设备列表：每台电脑一键「停用」。
   不加任何额外步骤、设置、开关、提醒。标注后记录进对应客户 SEO 或 GEO 的发布记录（标「外部回传」）。
4. 其他照方案：未标注只有生成码的人和超管能看；顾问只能标到自己已授权的客户；一次性 10 分钟配对码；同设备事件幂等；标注后同客户+模块+规范链接去重；改标/撤销留记录；旧 v1 原样；0.3.7 新增独立回传，旧配对继续用；不发邮件。
5. 第三轮审查 6 条非阻塞提醒按 SCOPE 落实：①搜索/导出与列表同一过滤（若不做导出就明说不做）②SEO、GEO 前端用独立的收件箱 API 模块，不注入 tenant/project ③同库确认见 infra ④平台链接向量——按本 SCOPE 取消 ⑤配对码猜测限速沿用现状并写入说明 ⑥零授权顾问可配对但标不了客户：界面提示「暂无可标注的客户，请联系超管授权」，超管可代标。
