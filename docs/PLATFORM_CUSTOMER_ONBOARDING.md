# 平台客户开户流程

统一入口：`/platform/customers` → `新建客户`。

开户向导按以下顺序调用现有接口，不新增数据库表：

1. 建立客户主档：客户名称、品牌名称、行业和业务说明。
2. 选择并开通 SEM、SEO、GEO 中的一个或多个模块，分别设置正式/试用和到期日。
3. 选择 SEO 或 GEO 时必须填写官网。向导会分别创建首个 SEO 网站和 GEO 项目；后续多网站仍在各模块内维护。
4. 有账号管理权限时，可同时创建限定到该客户的登录账号并选择现有角色。
5. SEM 不保存推广平台密码；客户创建完成后继续走百度 OAuth 授权。

开户由多个已有接口顺序完成，不宣称跨接口事务。如果中途失败，前端会关闭开户弹窗、保留已经完成的客户和模块，并明确显示客户 ID 与完成项；管理员应在客户列表继续补齐，不能再次提交同一客户以“重试”。

权限边界：

- 客户和模块需要 `settings.customers=edit`。
- 同时创建账号需要 `settings.accounts=edit`。
- 创建 SEO 网站与 GEO 项目仍受对应模块资产权限控制。内置超级管理员具备这些权限；自定义平台管理员需要同时获得相应权限。
