# GEO 第四批：机会进入任务与同题复测

日期：2026-09-05。所有改动保留本地，未提交、推送或部署。

## 已完成

- 信源机会表新增「创建 / 打开任务」。调用专用 GEO 接口，提交问题及本组可用快照 ID；建议内容由后端重新计算，不采信客户端传入的观察结论。
- 创建前检查客户权限、问题归属、快照归属和当前采样资格。证据缺失或已不满足条件返回 409，提示刷新并复核。
- 对同题持有事务行锁，并检查是否已有非 archived/cancelled 任务。有则打开已有任务，不覆盖其简报或补写证据；无则创建官网草稿，继承现有业务和优化期次关联，继续复用原任务流程。
- 机会依据存入任务现有 brief JSON，包含问题、样本 ID、数量、原因、建议和引用证据。任务接口将来源单独返回，普通简报编辑保留服务端已有来源，避免编辑器覆盖历史依据。没有新增模型字段或迁移。
- 编辑器新增「任务来源与复测依据」，可打开原始快照，并跳转到同题采样页。这里展示创建时记录，不随新的采样结果自动重写。
- 创建按钮防止重复点击；请求期间切换客户不会跳转到旧客户任务。编辑器只在来源任务属于当前客户时展示来源区域。

## 边界

- 没有真实数据库并发测试或登录页面的浏览器端到端验收。行锁只协调采用本入口的问题锁的请求；其他旧建任务入口未统一锁协议，因此尚无跨所有入口的全局唯一保证。
- 同题已有任务会直接复用，包含 published 状态；不会自动新建下一轮任务，也不会悄悄修改已有任务的来源。
- 请求最多包含 1000 条快照，超过时页面提示缩小观察窗口。
- 来源记录在现有 JSON 中，不是不可篡改审计存储；快照可能后续被编辑或删除，记录的引用仍需核验。
- 同题复测按钮仅打开采样页面，不会自动执行付费采样、生成文章、发布内容或宣称效果提升。后续可接入明确的前后窗口比较，但需先统一旧指标路径并完成实库验收。
