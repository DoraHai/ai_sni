📘 完整授权流程
1
系统拼接授权链接
本页生成 u.baidu.com/oauth/page/index 链接，包含 platformId / 回调地址 / state（防 CSRF）
2
客户超管在百度授权
客户打开链接 → 登录百度推广超管账号 → 同意授权 → 百度自动回调本平台
3
系统接收 code + 换 Token
回调 URL 接收 code，调 oauth/accessToken 换取 accessToken（24h）与 refreshToken（30 天）
4
拉取子账户列表
用超管 Token 调 getUserInfo(needSubList=true) + MccFeedService/getUserListByMccid
5
触发首次同步
异步调用 BulkJobService/getAllObjects 拉取所有计划 / 单元 / 关键词 → 进入「首次同步」页观察进度
⏱ accessToken 自动刷新
Token 23 小时后由系统自动用 refreshToken 续期，无需运营干预。refreshToken 30 天到期前 7 天会弹出提醒，需客户重新授权。
