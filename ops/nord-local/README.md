# 诺德首次接入

默认生产服务器、客户 1 / SEO 网站 1、公众号文章、北京时间、每日最多 1 条、间隔 1 小时，全天可排期。普通管理设置折叠保留。首次接入不要求填写这些参数。

打开 `https://gsnipers.snipers.com.cn/customer-workbench/?console=platform&setup=nord`，以正常实名管理员会话操作。

1. 点击创建配对码、复制短期码。在本机“诺德接入”菜单点击“从管理台复制的配对码继续”，确认这台电脑。
2. 点击“打开公众号扫码登录”，本人扫码；在公众号“设置与开发 → 公众号设置”打开账号信息页，再点击“确认账号并复制接入信息”。程序只从该官方页面的可见正文读取唯一原始 ID，不读取 Cookie、密码或登录 token。
3. 在管理台点击“读取本机已确认账号”，核对原始 ID，确认该账号可用于诺德。确认将当前实名管理员分配为网站顾问、创建浏览器人工发布连接、保存账号绑定，并为没有既有规则的新账号保存默认发布规则。既有规则不覆盖。
4. 本机自动同步刚确认的诺德绑定，保存任务配置、启动人工接收器并登记交接能力；无需输入账号、设备或项目编号。菜单的“同步已确认的诺德绑定”保留为手动检查入口。账号确认资料在 15 分钟内有效，过期需重新确认。

使用 PowerShell 7 单独运行 `launch.ps1`。它先核验固定的原始执行包清单及全部 85 个文件，自动打开官方扫码登录窗口。伴随启动器不修改原包，也不复用旧验收目录；地址固定 HTTPS，短期码只在明确点击时读取剪贴板和提交到原配对入口。原包继续负责请求校验、设备凭据保护和未知结果保护。

账号观察文本仅是人工确认的接入资料，不是平台身份签名或发布验收证明；管理台再次确认所有权，服务端每次重读实名角色权限和客户范围。账号信息读取必须在真实扫码后验证。账号设置页改版或不能读到唯一原始 ID 时会停在待核对状态，不猜账号。

接入不创建稿件审核、发布授权或真实发文；SDK 能力注册、任务下发、人工发表、真实链接和原模块结果回传仍须分别跑通。公众号官方网页由本机伴随窗口持久保存人工登录会话，和旧验收账号隔离；它不代表 SDK 的自动提交能力。

生产准备接口仅处理诺德网站 1，要求当前实名超管及 SEO 内容/网站编辑权限。顾问分配、浏览器连接和配置审计在一个事务中完成；没有 DDL、角色权限调整、其他业务服务重启或真实发布。接入后仍有独立的账号绑定和账号规则事务，响应丢失时只读核对已保存状态，不自动重做结果未知的写入。
